| 方向 | 表达与构造 | 主色与理由 |
| --- | --- | --- |
| A · 探箱 `a-box-cat/` | 正面猫头从单个箱体探出，两爪搭在箱沿。箱体只是一条容器轮廓，内部没有网格；眼睛朝一侧看，让猫像刚发现需要取用的工具。 | 橘 `#FF9A3D`，深墨剪影 `#202522`。温暖、亲近，连接纸箱与日常收纳的联想，避开纯正红和参考图的黄色。 |
| B · 侧目 `b-side-eye/` | 外张三角耳、宽下颌、圆眼和偏向同侧的圆瞳；脸内两条短负形作胡须。靠头部建立识别，表情保留一点不动声色的小脾气。 | 钴蓝 `#3155F5`，暖白 `#FFF8E9`。清晰、有数字工具感，反白后仍有稳定的轮廓与视线。 |
| C · 盘尾 `c-coil-cat/` | 脸偏右上，身体收成一团，尾巴沿左下回卷；偏侧的弯曲负形避免做成正中笑嘴，轮廓像给自己留出一个窝。 | 偏橘珊瑚 `#F48B73`，深墨 `#222524`。柔和黑色体量，保留俏皮感；色相与纯红拉开。 |
| D · 坐守 `d-sitting-cat/` | 两爪落地的静止坐姿，低位回卷的尾巴与身体相接。用姿态表达安静常驻，不做招手或奔跑动作。 | 墨黑 `#252B2D`，暖白 `#F6EEDB`。采用工作单允许的深色探索，减少常驻伙伴的喧闹感。 |

**本轮优先推荐 A · 探箱**：猫与 cubby 的关系直接，两只搭在箱沿的爪提供记忆点，也能保留为菜单栏单色标记。B 适合更偏重大眼表情的取向。所有方向均为提案，尚未由维护者选择。

## 编辑与文件

每个方向均提供三个 SVG：

- `source.svg`：主色满版底，背景对象为 `full-bleed-background`，前景颜色由根元素 `color` 控制。
- `mono.svg`：透明背景单色母版，保留圆瞳和主要表情；眼白、箱口、尾缝均为真实透明负形。
- `menu-template.svg`：16pt 单色简化稿，也是 16px 位图的小尺寸构形。统一去掉瞳孔；B 去掉胡须细线，C/D 的眼孔略收小，保证两个眼睛各自清楚。

所有构形均为手工设计的点位、几何及贝塞尔曲线。圆角直线交接、三角耳的圆钝尖端使用相切曲线；对象按猫头、箱体、爪、眼孔、瞳孔、身体、尾巴命名。没有描摹位图、嵌入参考图片、字体轮廓、滤镜或外部图形引用。复合路径使用 `evenodd`，各闭合子路径可拆开编辑。D 的整体与尾巴分组有平移，用于安排画布重心及尾部间隙。

`index.html` 为离线评审入口。主色大图可点击打开 1024px 原图；128 / 32 / 16px 按原生像素展示。展开卡片可看单色 1024px、主色在浅深外部背景下的预览，以及透明黑白模板。

每方向 20 张 PNG，共 80 张：主色四个尺寸各一份；单色四个尺寸 × 浅深背景；16pt 模板黑/白 × 1×/2× × 透明/背景语境。主色采用满版底，对外部浅深背景保持相同。2× 模板文件为 32 × 32px，评审页显示为 16pt。

16px 预览使用可编辑的 `menu-template.svg` 构形，再配对应主色或单色；大尺寸保留圆瞳表情。菜单栏识别建立在三角耳、头身关系、箱体或卷尾剪影上；眼睛仅保留清楚的负形。

### 复现本轮检查

需要 Python 3.10+、CairoSVG 2.9.1、Pillow 13.0.0、svgpathtools 1.7.2，系统动态链接器应能找到 Cairo。按仓库规则把依赖环境放在仓库外，再执行：

```sh
python render_previews.py
python validate_round.py
```

脚本仅重建和检查本轮评审资产，不生成 ICNS，不接入应用，不写应用目录。`preview-manifest.json` 记录相对路径、尺寸与实际使用的构形文件。

## 验证记录

- 12 份 SVG 均为可编辑矢量；21 个路径对象、524 处非零切线接点全部闭合并相切，最大偏差约 0.000203°，检查阈值为 0.1°。原生圆角矩形和圆分别承担爪及瞳孔等部件。
- 80 张 PNG 的尺寸、主色满版不透明度、模板透明区检查通过；1024px 检查曲线及留白，128px 检查视觉重量，32px/16px 检查眼睛、箱口、尾缝与尾部间隙。
- 16pt 模板在 1× / 2× 下均保留一个连贯剪影；按眼睛坐标检查两个负形分属独立区域，中心完全透明。A 的箱口、C 的尾缝也各保留独立开口，未裁到画布边缘。
- 浏览器在 1680px、1280px 与 390px 视口检查；无破图与横向溢出，原图展开及背景语境对照可用。94 个本地资源 / 文件链接均返回 200。
