# Cubbix Logo · R03 · 2026-10-28

维护者已选定 [R02 A「探箱」](../R02-2026-10-28/README.md)。本轮只精修线条与前后层次，沿用橘色 `#FF9A3D`、深墨 `#202522`、大圆眼、侧目圆瞳、三角耳及单个箱体，不扩展概念。

## 收到的反馈

猫头侧面原有竖直与斜直线段，脸颊缺少外鼓后收向下巴的连续变化；头下缘插入箱沿，侧面出现尖刺；原有圆角矩形爪伸进开口，在箱口形成机械的凸起与凹尖角。

## 三个受控变体

- **A1 · 只改头**：替换头部外轮廓，保留 R02 箱体位置、箱口和原爪的形状与层次，方便单独观察脸颊变化。
- **A2 · 只改爪与层次**：保留 R02 头部路径，调整前后遮挡和负形间隔，使用外垂的豆形爪。
- **A3 · 合并精修**：同时采用新的连续猫脸、豆形爪和层次分隔。

A1、A2 是隔离变量的对照稿；完整处理反馈以 A3 为准。各变体都将头、箱体、左爪、右爪保存为四条独立、具名的路径。

## 线条与层次规则

所有数值均以 128 × 128 的源画布为单位，1024px 渲染时 1 单位对应 8px。

### 头侧与收口

A1/A3 的耳根从 y=36 开始，到完整下巴 y=82，左右各用 5 段连续三次样条；这一段没有直线。脸颊先外鼓，再向下巴收拢。内部样条连接为 C2，轮廓同时检查切线方向与有符号曲率的 G2 连续。

三角耳仍有直边，耳尖与额头内侧转角采用零端点曲率的过渡，直边进入曲线处保持 G2。额头凹角有足够的转弯长度，避免窄小缺口。

A2/A3 的完整头部路径仍保留到 y=82，处于箱沿之后；遮挡蒙版将可见下缘收在 y=72，箱体前沿在 y=76，形成 4 单位留白。可见收口从 y=60 与头侧曲线作 G2 接合，再平顺进入遮挡边界；验证同时检查完整头侧和可见收口。头下缘不会穿过箱沿露进开口。

### 箱体与豆形爪

- 箱体保持 **88 × 44**，开口保持 **72 × 28**，层次稿整体下移 4 单位；比例不变。
- A2/A3 的爪为封闭的 C2 豆形曲线，上缘饱满，朝箱沿外侧下垂；左右各为独立路径。几何交叉和 1024px 遮罩检查均确认爪不进入箱口。
- 箱沿被爪遮挡的可见端部作圆端，避免交线留下凸刺。可见箱沿保留上沿和箱身的前后关系，底部仍是同一个容器。
- 分隔以 **4 单位**为基准。A3 在 1024px 二值轮廓中的头—爪最窄间隔约 **4.16**，爪—箱体约 **4.06**；头—箱沿为 **4**。A2 保留旧头，头—爪间隔较宽，约 5.58–5.79。
- 本轮统一使用无趾缝主稿，先评审轮廓与交接关系。

### 圆角体系

完整精修稿 A3 的凹角最小曲率半径统一为 **R4**：额头内侧的曲率连续转弯最小半径为 4，箱口内角为圆弧 R4。

凸角分三级：**R1 耳尖、R4 爪与可见端帽、R8 箱体外角**。自然脸颊和遮挡收口为变曲率曲线，最小曲率半径分别约 9.70、10.09，均满足 R8 的下限。豆形爪的最小曲率半径为 4；无需把自然轮廓拆成多个任意圆角值。

A1 保留旧箱口与旧爪，A2 保留旧头，这些对照部分仍使用 R02 的原曲线。圆角体系与完整反馈处理以 A3 为准；对照稿的保留项已在页面说明。

### 16px / 16pt 光学校正

A2/A3 小图将分隔扩大到 8 单位，箱体在 R02 基础上整体下移 8 单位，爪向外、向下略调；最后以 15/16 比例、4 单位内边距安放整幅剪影。缩放后的主分隔约 7.5 单位，在 16px 下接近 1px。

小图省去瞳孔，眼孔半径从 12 调为 10、上移 4 单位；A1 对照保留 R02 小图的爪与层次。所有模板的两个眼孔在 1×、2× 下都保持独立。主色及单色的 16px PNG 使用对应的可编辑 `menu-template.svg`，大尺寸保留原有圆瞳与侧目神态。

## 复现与验证

需要 Python 3.10+、Pillow 13.0.0、svgpathtools 1.7.2、SciPy 1.18.1，以及 Node.js 和 `@resvg/resvg-js` 2.6.2。依赖放在仓库外，Node 模块须可通过模块搜索路径解析（例如设置 `NODE_PATH` 指向该环境的 `node_modules`）。

```sh
python render_previews.py
python validate_round.py
```

渲染使用 resvg 的 SVG 蒙版实现；脚本只生成本轮评审资产，不是应用发布管线。`preview-manifest.json` 记录图片尺寸，`geometry-spec.json` 记录坐标规则，`validation.json` 保存实际检查数据。

- 新头部各 19 个接点、豆形爪各 12 个接点的 G2 检查通过；最大切线偏差小于 0.000004°，最大曲率跳变小于 0.00000002 / 单位，阈值分别为 0.001° 与 0.000001 / 单位。
- 完整头侧无混入直线，可见收口也验证了与头侧的曲率连续；前后遮挡、4 单位间隔及爪与箱口无交叉检查通过。
- A1 保留旧箱体和旧爪，A2 保留原头部路径，变体控制检查通过；四个主体保持独立路径。
- 72 张 PNG 的尺寸、主色满版、透明模板检查通过。1024/128/32/16px、浅深单色、16pt 黑白 1×/2× 均复核，黑白模板 alpha 一致，眼孔保持独立。
- 菜单栏为静态模板研究，未接入应用；仓库当前未提供 `scripts/selftest.sh`，未运行应用自测。

- 浏览器在 1680px、1280px、390px 视口检查：无横向溢出或破图；右侧局部及三组尺寸面板均可展开，原生 128px 图片保持 128 CSS px。89 个本地资源 / 文件链接均返回 200。
