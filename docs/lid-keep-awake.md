# 合盖保持：签名测试版与维护者验收

## 维护者：安装签名测试版

这些步骤只由维护者执行。测试会主动改变系统电源设置，并安装 root LaunchDaemon；先确认能恢复睡眠，再进行合盖和故障场景。软件无法在“即将合盖”之前收到公开系统通知。

1. 使用带 Developer ID 证书和公证配置的构建环境，检出此 PR。开发构建和 ad-hoc selftest 包不能用于验证特权功能。不要改版本号或上传 Release。
2. 在仓库根目录构建签名、公证测试包（选择实际架构）：

   ```sh
   CGO_ENABLED=0 GOTOOLCHAIN=go1.27.1 go run github.com/egoist/mygo/cmd/mygo@v0.6.2 build -platform darwin/arm64
   ./scripts/check-helper.sh build/darwin-arm64/Cubbix.app
   codesign -v -R='anchor apple generic and certificate leaf[subject.OU] = "P93GN4N3DC" and identifier "cubbix-helper"' build/darwin-arm64/Cubbix.app/Contents/Resources/bin/cubbix-helper
   ```

   构建脚本先固定助手 identifier，再由 MyGo 施加 Developer ID 嵌套签名与整体签名。任一校验失败时不要安装。
3. 退出正在运行的 Cubbix，用 Finder 将测试包放到 `/Applications/Cubbix.app`，再启动。其它位置只显示不支持。不要直接运行包里的 helper，也不要手动绕过副本校验。
4. 只读记录 `pmset -g` 的 `SleepDisabled`（应为 0）和完整电源设置。若原来为 1 且来源不明，先核对外部工具，不开始本轮。
5. 点猫标 → 合盖开关。由维护者在系统框内授权一次；安装会复制到 root 目录、校验**临时副本**的 Team ID 与 identifier、原子替换、写 plist、bootstrap。取消不应循环弹框。
6. 每项只改一个变量，结束后只读确认 `SleepDisabled=0`。恢复失败时，点状态行 alert → “强制恢复睡眠”，授权后再读回确认。助手在线报外部设置时不会提供这个按钮。

## 实现中的保守修正

- Tooltip 不接收指针，恢复／允许动作使用点击 alert 的锚定 popover；其它静态提示仍用 tooltip。
- Go 初始签名是 `a.out`，由构建脚本显式固定 identifier，不放宽 root 安装 requirement。
- MyGo 的 `buildCommand` 在编译前运行；没有 bundle 后处理钩子，仍只使用 T3。
- 电量以 IOKit Current/Max 为唯一可信来源；不解析未文档化文本后绕过 Max 检查。AC 的未知电量也拒绝开启，持续未知或达到下限则恢复。
- 未确认的动作选择只暂存，确认 1 后才写偏好；快捷键不触发安装，URL 还要求显式 1–480 分钟。
- 不信任权限／所有者异常的 journal 路径，启动失败并保持现值；可信 root journal 即使内容损坏也先恢复。不能把无法读取路径当成覆盖外部设置的依据。
