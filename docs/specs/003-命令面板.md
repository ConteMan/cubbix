## 1. 使用场景与键盘路径

### 1.1 与卡片面板（001）的分工

| | 卡片面板（001） | 命令面板（003） |
| --- | --- | --- |
| 打开方式 | 点菜单栏猫标 | 全局快捷键 ⌥.（或 `cubbix://palette`） |
| 主要用途 | 看状态（剩余时间、进程、窗口列表）+ 单点高频操作 | 不用鼠标、一次做完任何操作 |
| 输入 | 鼠标为主，Tab 可遍历 | 键盘唯一必需 |
| 生命周期 | 点外部收起 | Esc／失焦／执行后收起，常驻内存但默认不可见 |

两者不互相替代：001 的菜单栏面板保留「看」的价值（常亮剩余时间、JSON 窗口列表），命令面板不重复显示这些状态（低信息密度，§7.4）。同一个动作在两个入口里必须落到同一个函数，避免出现两套语义（§2.5 的接入表）。

### 1.2 操作清单与键盘路径

`⌥.` = 呼出面板，`↩` = 回车执行，`⌘K` = 动作列表，`esc` = 收起。下表「键盘路径」一列都在面板内完成，不含鼠标。

| # | 场景 | 频率（估计） | 键盘路径 | 步数 |
| --- | --- | --- | --- | --- |
| 1 | 开会／开始编译，开 1 小时常亮 | 每天多次 | ⌥. → `常亮 1h` → ↩ | 3 |
| 2 | 用记忆的时长开常亮 | 每天多次 | ⌥. → `常亮` → ↩ | 3 |
| 3 | 停止常亮 | 每天多次 | ⌥. → `停止` → ↩ | 3 |
| 4 | 开 45 分钟「仅保持任务」 | 每天数次 | ⌥. → `常亮 45m` → ⌘K → `仅保持任务开启` → ↩ | 5 |
| 5 | 一直开到某个时刻 | 每周数次 | ⌥. → `常亮 until 18:30` → ↩ | 3 |
| 6 | 不限时开常亮 | 每周数次 | ⌥. → `常亮 ∞` → ↩ | 3 |
| 7 | 新建 JSON 窗口（自动读剪贴板） | 每天多次 | ⌥. → `json` → ↩（或既有 ⌃⌥⌘J） | 3 |

补充规则：

- 面板内**不显示**常亮剩余时间、JSON 窗口内容摘要等状态；想看状态就点猫标（001）。
- 已经在用 ⌃⌥⌘K／⌃⌥⌘J 的人不需要改用面板：两个全局快捷键保持原样（`awake_app.go:102`、`json_app.go:54`）。
- 面板执行失败时**不收起**（§6.2），失败信息就地显示，用户可以直接改参数重试。

### 1.3 为什么是 ⌥.

| 候选 | 冲突情况 | 结论 |
| --- | --- | --- |
| `⌥.`（Alt+Period） | 系统与常见应用未占用；Carbon 热键表里有 `.`（`mygo@v0.6.2/internal/darwin/hotkey.go:29-42`，`.` = `0x2F`） | **采用** |
| `⌘Space`、`⌃Space`、`⌥Space` | 输入法切换、Spotlight、Raycast 等第三方启动器 | 不用，已写进系统冲突表（`awake_view.go:308`） |
| `⌃⌥⌘K`／`⌃⌥⌘J` | 已给常亮与 JSON 使用（`config.go:36`） | 不重复占用 |
| `⌘,` | 设置窗口（`main.go:228`） | 不用 |

已知取舍：美式键盘上 `⌥.` 输入 `≥`。全局热键由 Carbon 的 `RegisterEventHotKey` 注册（`mygo@v0.6.2/internal/darwin/hotkey.go:58-104`），注册后这次按键不再交给前台应用，`≥` 也就打不出来——这是 Carbon 热键的行为语义，**本机未实测**（§6.4 第 12 项），验收时会确认。它属于用户可自行改掉的默认值，不在应用里做例外处理；改动只走设置页录制（§2.4）。需要输入 `≥` 时，可用输入法面板或字符检视器，也可以在设置里把面板快捷键改成其他组合。

## 2. 命令模型

### 2.1 数据结构（只给签名，不给实现）

新文件 `commands.go`：

```go
// 参数类型。目前只有常亮需要参数，新增参数类型时在这里扩展。
type commandParam int

const (
	paramNone        commandParam = iota // 不接受参数
	paramAwake                            // 常亮：时长 / 直到 / 不限时 / 用记忆设置
)

// 一条命令。命令是纯数据 + 函数字段，不持有窗口。
type command struct {
	ID       string                        // 稳定标识，用于收藏、最近使用与 URL 路由，如 "awake.start"
	Title    func(locale string) string    // 列表标题；静态命令用 staticTitle("R05Start")
	Keywords []string                      // 可搜索的别名与关键词（手写，含拼音全拼与首字母）
	Tile     string                        // "awake" / "json" / ""（通用）；仅用于分组图标与归属
	Icon     string                        // Lucide 文件名，见 §7.2
	Param    commandParam                  // 参数类型
	Available func(a *application) bool    // 可用条件，nil 表示恒可用
	Run      func(a *application, req request) error
	Actions  func(a *application, req request) []paletteAction
}

// 一次执行请求。Arg 是命令前缀之后的原文，Value 是解析结果。
type request struct {
	Command *command
	Arg     string     // 未解析的原文，例如 "1h30m"、"until 18:30"
	Awake   awakeArg   // Param == paramAwake 时的解析结果
}

// 动作列表里的一项（⌘K 打开）。
type paletteAction struct {
	ID       string                     // 稳定标识，如 "awake.start.tasks"
	Title    func(locale string) string
	Icon     string                     // 空表示不画图标
	Group    int                        // 0 主操作、1 参数、2 组织（收藏）
	Checked  func(a *application) bool  // 单选态（模式、时长），nil 表示不是单选
	Available func(a *application) bool
	Run      func(a *application) error
}

func staticTitle(text string) func(string) string { return func(string) string { return text } }
```

`awakeArg`（`commands.go`，与 §4 的语法一一对应）：

```go
type awakeArgKind int

const (
	awakeArgDefault   awakeArgKind = iota // 用记忆设置（a.selectedSession()）
	awakeArgMinutes                       // 固定分钟数
	awakeArgUntil                         // 直到某时刻
	awakeArgUnlimited                     // 不限时
)

type awakeArg struct {
	Kind    awakeArgKind
	Minutes int    // awakeArgMinutes
	Until   string // awakeArgUntil，"18:30"
	Error   string // 非空表示非法，值是资源键（DurationError / TimeError）
}
```

### 2.2 注册表

```go
// commands.go
func (a *application) commands() []*command      // 每次显示面板时组装：常亮 + 已打开的 JSON 窗口 + 通用
func (a *application) awakeCommands() []*command
func (a *application) jsonCommands() []*command  // 依赖 a.jsonDocuments，动态生成
func (a *application) systemCommands() []*command
```

规则：

- 注册表**不做全局单例**，每次 `showPalette()` 现算一次。JSON 窗口会随时增减，缓存反而要处理失效。
- `Available` 在组装时求值一次即可（面板是临时浮层，显示期间不刷新列表）；不在 `Available` 里做耗时工作。
- 命令顺序即列表里的稳定顺序（用于打分相同时的次序）：常亮 → JSON → 通用。

说明：

- `settings.page` 是四条独立命令（通用／格子／快捷键／关于），共用 `settings.page` 前缀 ID + 页名后缀，例如 `settings.page.shortcuts`；这样收藏「快捷键设置」是稳定的一项，而不是一条带参数的命令。页码沿用 `a.page` 的既有取值：通用 0、关于 1、格子 2、快捷键 3（导航顺序见 `main.go:463` 的 `[]int{0, 2, 3, 1}`）。
- `json.window` 的标题来自文档名，属于**动态标题**；ID 用文档自带的序号：`json.window.<jsonDocument.number>`。`number` 由 `addJSONDocument` 分配（`json_documents.go:46-52`），单调递增且不复用，窗口关掉后旧 ID 自然消失。**不要用切片下标**：`removeJSONDocument`（`json_documents.go:53`）会移位。
- JSON 窗口命令**不进收藏、不进最近使用**（§3.1），因为它们在文档关闭后即失效。
- `awake.mode.*`、`awake.until/custom/follow` 在卡片面板（001）里也有入口，语义必须与 `a.setMode`（`awake_app.go:75`）、`a.openAwakeDialog`（`awake_view.go:33`）完全一致，不允许复制实现。

### 2.4 配置与快捷键

`config.go` 的 `Config`（`config.go:14`）新增三个字段，放在 `AwakeShortcut` 之后：

| 字段 | TOML 键 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `PaletteShortcut` | `palette_shortcut` | string | `Alt+.` | 面板全局快捷键 |
| `PaletteFavorites` | `palette_favorites` | []string | 空 | 收藏的命令 ID，按收藏顺序 |
| `PaletteRecents` | `palette_recents` | []string | 空 | 最近执行，最多 5 条，最新在前 |

实现要点：

- 默认值写进 `defaultConfig()`（`config.go:36`）；`loadConfig`（`config.go:40`）先取默认值再 `toml.Unmarshal`，旧 `config.toml` 缺键时自动落到默认值，**不需要升 `configVersion`**（`config.go:12`）。
- 载入时规整：`PaletteShortcut` 为空串就写回 `Alt+.`；`PaletteFavorites` 去重、去空；`PaletteRecents` 去重、截断到 5 条。参照 `loadConfig` 末尾对 `JSONSplit` 的规整写法（`config.go:63-65`）。
- `Alt+.` 能通过既有解析链：录制时 `shortcutKey`（`awake_view.go:252`）把 `ui.KeyPeriod` 映射成 `"."`，`sameShortcut`／`knownShortcutConflict`（`awake_view.go:300`、`:308`）没有把 `Alt+.` 列为冲突；注册时加速度解析器接受单字符键（`mygo@v0.6.2/internal/accelerator/accelerator.go:157-167`），Carbon 键码表里有 `.`（`mygo@v0.6.2/internal/darwin/hotkey.go:29-42`）。

三个快捷键互斥：现有代码是两两比较（`awake_app.go:106`、`json_app.go:58`），加了第三个之后要统一。推荐改成槽位式：

```go
// awake_view.go
type shortcutSlot struct {
	Target   string // "awake" / "json" / "palette"
	Acc      string
	Enabled  bool
	Callback func()
}

func (a *application) shortcutSlots() []shortcutSlot
func (a *application) shortcutConflict(acc, target string) string // 返回错误键，"" 表示无冲突
```

改动点（函数名优先，行号为辅）：

| 位置 | 改动 |
| --- | --- |
| `awake_view.go:329` `recordShortcut` | 用 `shortcutSlots()` 取「本槽旧值 / 其它槽 / 是否启用 / 回调」，替换 `targetJSON` 的两分支 |
| `awake_view.go:397` `beginTileShortcutRecording` | 录制期间注销**三个**快捷键（现在是常亮与 JSON 两个） |
| `awake_view.go:416` `cancelShortcutRecording` | 恢复时重新注册三个 |
| `awake_view.go:433` `shortcutSettingsRow` | 支持 `target == "palette"`，标签键 `PaletteShortcutLabel`、录制键 `PaletteRecordShortcut` |
| `awake_view.go:379` `awakeSettings` | 快捷键页（`a.page == 3` 分支）加第三行录制，排在 JSON 之后 |
| `awake_app.go:102` `registerAwakeShortcut` / `json_app.go:54` `registerJSONShortcut` | 冲突判定改用 `shortcutConflict` |
| 并入 `palette.go` | `registerPaletteShortcut()`：`a.registerShortcut(a.config.PaletteShortcut, a.togglePalette)`；冲突时写 `a.paletteShortcutError` |
| `main.go:132` `settingsHeight` | 「快捷键」页改为按行数算：`content = rows*SizeRowHeight + (rows-1)*StrokeHairline`，`rows = 3`（002 落地后为 5）。最小窗 720 × 340 不变（关于页仍是最高的页） |
| `main.go:306` `ready` | 启动时注册面板快捷键；注册 `OnOpenURL` 与 `RegisterURLScheme`（§8.2） |

快捷键页从 2 行变 3 行，内容高度 3 × 48 + 2 × 1 = 146，加上下各 `Space24` 为 194，按 `Space4` 向上取整 196，小于最小高的余量 340 − 48 − 48 = 244，**不需要调整 `settingsMinimumSize`**。

### 2.5 常亮与 JSON 的接入（引用现有函数）

| 命令动作 | 直接调用 | 现有语义 |

## 3. 列表与搜索

### 3.1 分组

| 组 | 标题键 | 内容 | 显示条件 |
| --- | --- | --- | --- |
| 收藏 | `PaletteFavorites` | `config.PaletteFavorites` 里仍然存在的命令，按收藏顺序 | 非空才显示 |
| 最近使用 | `PaletteRecent` | `config.PaletteRecents`（最多 5），倒序最新在前 | 非空才显示 |
| 全部命令 | `PaletteAll` | 其余命令（按 §2.2 的注册顺序） | 恒显示；空时不显示标题 |

规则：

- 同一条命令只出现一次：先进收藏，再进最近使用，最后进全部。
- 输入关键词后**保留分组**，每组只显示命中的行；空组连标题一起隐藏。这样「收藏里的命令永远在同一个位置」，比打散重排更好记。
- 收藏与最近使用不包含 `json.window.*`（§2.3）。
- 分组标题不占选中位置：`ui.ListState.Header`（`mygo@v0.6.2/ui/list.go:93-97`）标记标题行，上下移动时跳过。

### 3.2 命令前缀与参数切分

面板输入框里只有一行文本，面板要自己判断「哪部分是命令、哪部分是参数」。规则按顺序执行：

1. 规范化：`strings.TrimSpace`，连续空白折成一个空格，其余原样（中文不用转小写，比对时对 ASCII 部分做 `strings.ToLower`）。
2. **前缀匹配**：对每条命令的搜索名（标题 + 每个 `Keywords`）检查——输入等于该名，或以「该名 + 空格」开头，或以该名紧接一个非字母字符（数字、`∞`、`:`、`-`）开头。命中者里取最长的一个，其余部分是参数原文。
   - `常亮 1h` → 命令 `awake.start`，参数 `1h`
   - `常亮1h` → 同上（中文输入法下用户常常不打空格）
   - `常亮` → 命令 `awake.start`，参数为空
   - `json items.json` → 命令 `json.window`，参数 `items.json`（此命令 `Param == paramNone`，参数只用于收窄列表，不参与执行）
3. **没有前缀命中**：整行当作查询词，只做搜索（§3.3），不产生参数。

前缀过长时 `常亮开关` 应当先命中 `awake.start`（关键词含「常亮」）还是被当成查询词？规则 2 只认「等于／前缀 + 空白 + 非字母」，`常亮开关` 会命中 `常亮` 前缀，余下 `开关` 变成参数 → 解析失败。为此加一条保护：**前缀命中的剩余部分如果能解析成合法参数就用，否则退回「整行当查询词」**。这样 `常亮开关` 变成一次普通搜索，`常亮 45m` 仍是带参数执行。

### 3.3 模糊匹配与排序

打分函数（纯函数，`commands.go` 内，单元测试覆盖）：

```go
// matchScore 返回最佳匹配得分；0 分表示不命中。
func matchScore(query, title string, keywords []string) int
```

| 层级 | 条件 | 得分 |
| --- | --- | --- |
| 1 | 标题完全相等 | 1000 |
| 2 | 标题以查询开头 | 900 − len(title) |
| 3 | 某关键词完全相等 | 800 |
| 4 | 某关键词以查询开头 | 700 − len(keyword) |
| 5 | 标题包含查询（子串，CJK 主要走这里） | 600 − 命中位置 |
| 6 | 关键词包含查询 | 500 − 命中位置 |
| 7 | 标题构成子序列 | 400 − 2 × 跳过的字符数 |
| 8 | 关键词构成子序列 | 300 − 2 × 跳过的字符数 |

- 大小写不敏感；空格分隔的多词查询按「每个词都必须命中」处理，总分取各词得分的和。
- 同分时的次序：标题更短者优先，再按 §2.2 的注册顺序（稳定排序，保证同一查询每次结果一致）。
- 子序列匹配只用于 ASCII（`jsonw` → `json.new`、`cl` → 常亮）；中文标题用子串匹配，避免出现「常亮」被拆成无意义单字命中。
- 不使用编辑距离（Levenshtein）：命令总数不到 20，纠错收益低，反而会让「1 个字之差」的误命中把正确项挤下去。

### 3.4 拼音：推荐不做拼音库，改为手写关键词

| 方案 | 代价 | 结论 |
| --- | --- | --- |
| 引入拼音库（映射表或 GBK 编码表） | 新依赖 + 数据表体积；AGENTS 要求固定版本、不从网络加载 | 不选 |
| 手写 `Keywords`（含全拼与首字母） | 每条命令 2–4 个词，十几条命令一次写完；漏写可用测试兜住 | **采用** |
| 完全不做拼音 | 中文用户输入 `cl` 找不到常亮，只能打中文 | 不选 |

因此 §2.3 的 `Keywords` 列里已经写好全拼（`changliang`）与首字母（`cl`）。配套测试：每条命令的 `Keywords` 至少 1 个；除归属词外全局不重复。归属词指 `json` 这种「同类命令共享的词」，允许同时出现在 `json.new` 与 `json.window` 上，测试按「同一 `Tile` 内最多共享一个词」实现。

### 3.5 空结果

只显示一个居中的 `search` 图标（`SizeIconLarge` = 24，`ColorTextDisabled`）与一行 `PaletteEmpty`（「无结果」／「No results」），`FontSizeSmall`。不写「试试其他关键词」这类整句说明（AGENTS「低信息密度」）。

参数非法**不是**空结果：命令仍然在列表里，只是行内 alert（§4.2）。

## 4. 参数输入

### 4.1 语法

只对 `paramAwake` 生效。解析函数 `parseAwakeArg(arg string, now time.Time) awakeArg`，输入已去掉命令前缀。规则按顺序匹配，全部大小写不敏感：

| 写法 | 结果 | 说明 |
| --- | --- | --- |
| 空 | `awakeArgDefault` | 用记忆设置：`a.selectedSession()` 会读 `config.AwakeMinutes`／`AwakeUntil`／`AwakeMode` |
| `∞`、`inf`、`infinity`、`unlimited`、`无限`、`不限`、`不限时`、`0` | `awakeArgUnlimited` | 与 `config.AwakeMinutes == 0` 同义（`awake_app.go:47-63`） |
| `until 18:30`、`到 18:30`、`直到 18:30`、`18:30` | `awakeArgUntil{Until:"18:30"}` | 只接受 24 小时制 `H:MM`／`HH:MM`，与 `untilTime` 的 `time.Parse("15:04")` 一致（`keepawake.go:182`）；校验时用同一个 `untilTime` |
| `45m`、`45min`、`45分钟`、`45 分` | `awakeArgMinutes{45}` | 分钟 |
| `2h`、`2小时`、`2 hour`、`2hours` | `awakeArgMinutes{120}` | 小时 |
| `1h30m`、`1h30`、`1小时30分钟`、`1h 30m` | `awakeArgMinutes{90}` | 组合写法，中间空格忽略 |
| `45` | `awakeArgMinutes{45}` | 裸数字 = 分钟（见 §10 待决定 4） |

范围与错误：

| 情况 | `Error` 键 | tooltip 文案（复用既有键） |
| --- | --- | --- |
| 无法解析的写法（`45x`、`abc`、`常亮开关` 的残部） | `DurationError` | 请输入有效的小时和分钟（1 分钟至 8760 小时 59 分钟） |
| 时长超出 1 分钟 – 8760 小时 59 分钟（合计 1–525659 分钟） | `DurationError` | 同上 |
| 时间格式错误或无法解析（`until 99:99`） | `TimeError` | 请输入 24 小时制时间，例如 02:30 |

上限与 `customDuration`（`keepawake.go:194`）保持一致；`until` 的时刻早于现在时由 `untilTime` 顺延到明天，不报错（既有行为）。

### 4.2 非法输入的表现

| 位置 | 表现 |
| --- | --- |
| 搜索框右端 | `triangle-alert` 图标，`SizeIcon`，`ColorDanger`，`Tooltip` 显示 `Error` 键的文案；图标用 `Focusable().Label(文案)` 提供无障碍名（照抄 `awake_view.go:473` 起的写法） |

| 修正输入 | 错误状态随下一次输入立即消失（重新解析） |

不使用对话框或整句错误行：错误只出现在图标 + tooltip 里，与设置页录制行的错误表现一致。

### 4.3 行内提示（右侧 hint）

| 解析结果 | hint 文案 |
| --- | --- |
| `awakeArgDefault` | 记忆时长的文本：`R05Half`／`R05Hour`／`R05Two`／`R05Four`，其它分钟数用 `PaletteMinutes`，`0` 用 `R05Unlimited`，非空 `AwakeUntil` 用 `PaletteAwakeUntil` |

## 5. Actions（⌘K）

### 5.1 交互形态

| 步骤 | 行为 |
| --- | --- |
| ⌘K（列表模式下） | 切换到动作列表：命令列表被替换，顶部多一行命令标题（图标 + 标题），下接当前命令的动作 |
| ⌘K（动作模式下） | 回到命令列表，保留原来的查询与选中行 |

## 6. 窗口行为

### 6.1 创建参数

```go
t := tokens(false, "zh-CN") // 尺寸与颜色与语言、主题无关
w := mygo.NewWindow(mygo.WindowOptions{
	Title:             "Cubbix",
	Width:             int(t.SizePaletteWidth),
	Height:            int(t.SizePaletteHeight),
	Hidden:            true,
	Frameless:         true,
	Transparent:       true,
	DisableResize:     true,
	DisableMove:       true,
	DisableMinimize:   true,
	DisableMaximize:   true,
	DisableFullScreen: true,
	Panel:             true, // 关键：不激活应用的浮层，可成为 key window
	Content:           ui.View(a.paletteView),
})
w.OnClose(func(e *mygo.CloseEvent) { e.PreventDefault(); a.hidePalette() })
w.OnBlur(a.hidePalette)
```

说明：

- `Panel` 会强制 `AlwaysOnTop` 与 `SkipTaskbar`、禁用最小化／最大化／全屏（`mygo@v0.6.2/window.go:530-535`），不需要另外设置。
- 不设 `DisableClose`：面板没有标题栏与关闭按钮，任何关闭请求（Esc、⌘W、`Window.escape`）都统一由 `OnClose` 拦成隐藏；设了反而多一个未验证的风格位。
- 不用 `SetIgnoreMouseEvents`：面板必须收点击（选行、输入框定位）。
- 不设置 `Vibrancy`：面板表面用 92% 不透明的 `ColorMenuSurface`（§7），比 HUD 毛玻璃在浅色桌面上更清楚，也省掉「有材质时不铺底色」的分支。
- 阴影用系统默认（不设 `DisableShadow`）：MyGo 在 flyout 里的注释说明透明窗口的系统阴影「由窗口绘制的内容生成」，因此跟随自绘圆角（`mygo@v0.6.2/internal/darwin/window.go:251-253`）。这一条只对 flyout 有实测记录，面板需要目视确认，见 §6.5 第 5 项。

### 6.2 显示、收起与位置

```go
func (a *application) togglePalette() {
	if a.shortcutRecording { // 录制期间不弹面板，否则会抢走按键
		return
	}
	if a.paletteVisible() {
		a.hidePalette()
		return
	}
	a.showPalette()
}

func (a *application) showPalette() {
	if a.palette == nil {
		a.createPaletteWindow() // 延迟创建：不按快捷键就完全不开窗口
	}
	a.palette.reset()      // query = ""、选中第一行、模式 = 命令列表、错误清空
	a.placePalette()
	a.palette.window.Show() // 不是 ShowInactive：面板必须拿到键盘
}

func (a *application) hidePalette() {
	if a.palette == nil || a.palette.window == nil { return }
	a.palette.window.Hide()
}

func (a *application) placePalette() {
	d := mygo.Screen.DisplayNearestPoint(mygo.Screen.CursorScreenPoint())
	w, h := a.palette.window.Size()
	x := d.WorkArea.X + (d.WorkArea.Width-w)/2
	y := d.WorkArea.Y + int(tokens(false, "zh-CN").SizePaletteTopOffset)
	if y+h > d.WorkArea.Y+d.WorkArea.Height { // 小屏兜底
		y = max(d.WorkArea.Y, d.WorkArea.Y+d.WorkArea.Height-h)
	}
	a.palette.window.SetPosition(x, y)
}
```

| 时机 | 行为 |
| --- | --- |
| 按 ⌥. | 未显示则显示并按鼠标所在屏幕定位；已显示则收起（同一个键开关） |
| 执行命令 | **先收起面板，再执行**；失败时重新显示并保留查询与错误（§6.3） |
| Esc | 收起（视图注册 `c.OnShortcut(0, ui.KeyEscape, ...)`，同时 `OnClose` 里 `PreventDefault` + 隐藏兜底） |
| ⌘W | 收起（与 Esc 同义，视图注册 `c.OnShortcut(ui.Cmd, ui.KeyW, ...)`） |
| 失焦 | 收起（`OnBlur`，`mygo@v0.6.2/window.go:1497`） |
| 点击别的窗口、切换应用、⌘Tab | 上面的失焦即可覆盖 |
| 打开设置页、新建 JSON 窗口、卡片面板弹出 | 面板失焦自动收起；不需要显式调用 `hidePalette` |
| 显示器拔掉／分辨率变化 | 显示中时按 §6.2 的 `placePalette` 重算位置（订阅 `Screen.OnDisplaysChanged`，`mygo@v0.6.2/modules.go:306`），不改变查询与选中行 |
| 退出应用 | `beforeQuit`（`main.go:379`）里隐藏面板窗口；`GlobalShortcut.UnregisterAll()` 已经覆盖快捷键 |
| 录制快捷键期间 | `togglePalette` 直接返回（§2.4） |

**绝不能做的事**（都会把面板变成「会切 Space 的窗口」或抢走前台）：

1. 不调用 `a.visibility(true)`（`main.go:175`）——它会把激活策略切成 `Regular`，MyGo 在策略变成 regular 时会 `activateIgnoringOtherApps:`（`mygo@v0.6.2/internal/darwin/app.go:370`）。
2. 不调用 `mygo.App.SetActivationPolicy`、`mygo.App.Activate()`。
3. 不用 `ShowInactive`：它只 `orderFrontRegardless`，不成为 key window（`mygo@v0.6.2/internal/darwin/window.go:755-768`），面板收不到键盘。
4. 不在视图里用 `Hidden` 开关代替 `Hide()`。

`main.go:329` 的 `OnActivate` 回调目前是「没有任何可见窗口就打开设置」。面板是 tool window，不进入这套判断；为避免用户在面板可见时误触激活（例如 Spotlight 打开 Cubbix），回调里加一行：面板可见时先收起面板再返回，不打开设置窗口。

### 6.3 焦点、Esc 与执行结果

| 主题 | 结论 |
| --- | --- |
| 输入框焦点 | 输入框用固定的 `Key` + `Element.Focus()`（每帧调用即持续持有焦点，`mygo@v0.6.2/ui/api_gen.go:3754-3767`），而不是只用 `AutoFocus`（只在元素首次出现的帧生效，`mygo@v0.6.2/ui/api_gen.go:2782-2791`）；这样面板隐藏再显示时焦点自动回到输入框。只有画「参数错误」的 alert 图标时才让它可聚焦，仍不抢输入框焦点 |
| ↑／↓ | 注册在输入框上（`OnShortcut(0, ui.KeyDown, ...)`，写法同 `awake_view.go:181-183` 的进程搜索框），移动选中并 `list.ScrollIntoView(row)`（`mygo@v0.6.2/ui/list.go:303`）；跳过分组标题行 |
| ↩ | 输入框 `OnSubmit`（`mygo@v0.6.2/ui/actions.go:43`）+ 视图根上的 `OverlayShortcut(0, ui.KeyEnter)` 兜底（输入法组合中不触发，见下） |
| 中文输入法组合中按 ↩／↑ | 组合过程由输入法消费，`TextInput` 只在提交后 `OnChange`；`OnSubmit` 应在组合期间不生效。这条**未实测**，见 §6.5 第 4 项 |
| Esc 的传递链 | 视图没接管的 Esc 会经 `ui/engine.settleKeys` 交给宿主（`mygo@v0.6.2/ui/input.go:903-915`），`Window.escape` 对 panel 直接 `close()`（`mygo@v0.6.2/flyout.go:241-254`），因此 `OnClose` 必须 `PreventDefault` 并改为隐藏 |
| 执行成功 | 收起面板；不弹任何提示（§9） |
| 执行失败 | 面板**不关**：`paletteState.errorKey` 记错误键，视图在对应行右侧画 `triangle-alert` + tooltip，`Invalidate()` 重画 |

### 6.5 未证实项、替代方案与风险

| # | 未证实的点 | 影响 | 替代方案 |
| --- | --- | --- | --- |
| 1 | 原生 UI 输入的完整键盘链路（不止 Esc） | 面板打不了字 = 功能不成立 | 先按本规格实现并在本机实测（§10 验收第 1 项）。若失败：显示面板时切 `Regular` 并 `Focus()`，代价是激活应用、前台菜单栏变成 Cubbix（Space 不切，因为面板加入所有 Space）；不影响其他功能，只是「不激活」这一优点退化为「不切 Space」 |
| 2 | 中文输入法在非激活面板上能否组合与选词 | 中文用户无法搜索 | 同上；另外可临时提供「关键词一律英文/拼音」的降级提示（不做默认） |

| 4 | 输入法组合期间 `OnSubmit`／↑↓ 的表现 | 可能在选词时误执行命令 | 验收时专项测；若误触发，改为「组合中不响应」，通过 `ui` 的 `HandleInput` 观察 `InputCompose` 事件（`mygo@v0.6.2/ui/handler.go:17-19`） |
| 5 | 透明面板的系统阴影是否跟随 12 圆角 | 可能看到矩形硬边 | 先按默认开启；若边缘不对，改 `DisableShadow: true` + 根视图 `Element.Shadow(0, Space8, Space24, 0, ColorOverlay)`（`mygo@v0.6.2/ui/api_gen.go:5263-5276`），此时窗口需要在左右与下方留出约 `Space24` 的透明边距、尺寸与定位随之变化（与 002 §3.6 同一个取舍） |
| 6 | `Regular` 状态下能否浮在别人的全屏 Space 上 | 开着设置窗口时在全屏应用里按 ⌥. 可能看不见面板 | 接受限制（与 001 一致）：此时用户正在用 Cubbix 自己的窗口，不为此切换激活策略 |
| 7 | `≥` 无法输入 | 美式键盘用户少打一个符号 | 文档写明（§1.3），并允许在设置里改键 |

## 8. URL scheme

### 8.1 路径与参数

Scheme 固定 `cubbix`。解析后 `u.Host` 是动作名，`u.Path` 是子动作，其余走 query。

| URL | 行为 | 参数 |
| --- | --- | --- |
| `cubbix://awake?minutes=60&mode=tasks` | 开启常亮 | `minutes`：0–525659 的整数，`0` 表示不限时；`mode`：`screen`／`tasks`；两者都可省，省则用 `config` 的记忆值（`awake_app.go:47`） |
| `cubbix://awake/stop` | 停止常亮 | 无 |
| `cubbix://awake/toggle` | 开／关切换（等价于 ⌃⌥⌘K，`awake_app.go:65`） | 无 |
| `cubbix://json/new` | 新建 JSON 窗口 | 可选 `blank=1` 不读剪贴板；可选 `text=`（URL 编码，长度 ≤ `jsonFileLimit`，即 64 MiB，`json_documents.go:15`） |
| `cubbix://palette` | 打开命令面板 | 无（等价于 ⌥.；面板会拿键盘但不激活应用） |
| `cubbix://settings?page=general\|tiles\|shortcuts\|about` | 打开设置的某一页 | `page` 非法或缺失时落在「关于」页（与 `main.go:256` 的「关于 Cubbix」菜单项同一写法：`a.page = 1`） |

工作单点名了 `awake`、`awake/stop`、`json/new`、`palette` 四条；`awake/toggle` 与 `settings` 是本规格**建议补充**的两条，理由见 §10 待决定 5。

### 8.2 注册与送达

| 环节 | 做法 | 依据 |
| --- | --- | --- |
| 声明 scheme | `mygo.json` 增加 `"urlSchemes": ["cubbix"]`（该文件当前没有这个键） | macOS 只把 Info.plist 里 `CFBundleURLTypes` 声明的 scheme 交给应用（`mygo@v0.6.2/docs/app.md:127-146`、`mygo@v0.6.2/internal/darwin/deeplink.go:12-14`） |
| 成为默认处理者 | 启动时 `mygo.App.RegisterURLScheme("cubbix")`，失败只记日志、不阻塞启动 | `mygo@v0.6.2/deeplink.go:147-160`；macOS 上未声明时返回错误（`internal/darwin/deeplink.go:20-23`），已声明时调 `LSSetDefaultHandlerForURLScheme`（`:24`） |
| 接收 URL | `mygo.App.OnOpenURL(func(raw string){ a.handleURL(raw) })`，**在 `App.Run` 之前注册**，这样「用 URL 启动应用」的那一次也能收到 | `mygo@v0.6.2/app.go:460-466`、`docs/app.md:127-137`；启动参数由 `launchArgs` 在 ready 之后投递（`mygo@v0.6.2/deeplink.go:189-199`） |
| 应用已在运行 | macOS 经 `application:openURLs:` 把 URL 交给现有实例（`mygo@v0.6.2/internal/darwin/app.go:326`） | 同上 |
| 回调线程 | 实现时统一 `mygo.RunOnMain`，不赌调用线程 | 全局快捷键的回调在主线程（`mygo@v0.6.2/docs/native.md` 的 Global shortcuts 一节）；`OnOpenURL` 也来自主线程（AppKit 的 `application:openURLs:`，`mygo@v0.6.2/internal/darwin/app.go:326`；启动时由主线程的 `launchArgs` 投递，`mygo@v0.6.2/deeplink.go:189-199`） |

`cubbix://palette` 会显示面板并拿到键盘（与 ⌥. 等价），这是唯一一条会「抢键盘」的 URL；其余 URL 不显示任何窗口（`json/new` 与 `settings` 本来就会打开各自窗口，属于它们自己的既有语义）。

### 8.3 校验与安全

URL 来自任何应用或网页（scheme 一旦声明就对系统全局有效），按**不可信输入**处理：

1. `url.Parse` 失败 → 丢弃。`u.Scheme` 必须等于 `cubbix`（大小写不敏感）。
2. `u.Host` 必须在白名单 `{awake, json, palette, settings}` 里；`u.Path` 去掉前导 `/` 后同样按父动作校验：`awake` 只接受空、`stop`、`toggle`；`json` 只接受 `new`；`palette` 与 `settings` 只接受空。其余一律丢弃。
3. `minutes`：`strconv.Atoi`，必须 `0 ≤ n ≤ 525659`；不是整数或越界 → 整个请求丢弃（不做部分执行）。
4. `mode`：只接受 `screen`／`tasks`，其他值 → 整个请求丢弃。
5. `text`：长度 > `jsonFileLimit`（`json_documents.go:15`，64 MiB）→ 丢弃；只当作文档内容，不当作路径。
6. **不做的事**：不接受文件路径、不读任意文件、不执行 JS／`Eval`、不改 `config`（URL 触发的常亮只改会话，不改记忆时长；这一点与面板不同，面板会写 `AwakeMinutes`）、不打开任意 URL、不注册新快捷键。
7. 未知 query 参数忽略；重复参数取第一个（`url.Values.Get` 的行为）。
8. 幂等与限流：同一 URL 连续到达时按普通请求处理（`awake` 重复开启等价于重置时长），不加队列也不报错。

### 8.4 Raycast Quicklinks 与「快捷指令」示例

Raycast Quicklink（Raycast 的「保存为快捷链接」功能，属于对方产品的公开用法，本机未逐版本核对）：

1. Raycast → Create Quicklink。
2. Name：`常亮 1 小时（仅任务）`；Link：`cubbix://awake?minutes=60&mode=tasks`。
3. Hotkey 设成不与 Cubbix 冲突的组合（例如 `⌃⌥⌘1`），Open With 保持 Default。
4. 触发后 Raycast 通过系统打开该 URL，Cubbix 执行，不激活 Cubbix。

macOS「快捷指令」（Shortcuts.app）：

3. 需要的话再接「显示通知」动作作为执行反馈（Cubbix 自身在 URL 路径上的提示见 §9）。

## 9. 与 001、002 的关系

| 关系 | 结论 |
| --- | --- |
| 与 001（卡片面板） | 两者共用同一批动作函数（§2.5），不各自实现。卡片面板仍由猫标左键打开；两者互不遮挡：001 的面板锚在猫标下方，003 的面板在屏幕上方居中。点猫标时面板是否自动失焦要实测（与 §6.5 第 3 项同一个原因：菜单栏上的点击可能不让 key window 失焦）；若不失焦，就在猫标点击回调里显式调 `hidePalette()`——这一行在 001 落地时必须补上 |
| 与 002（快捷键反馈） | **命令面板执行成功不弹屏幕提示**：面板本身就是反馈（用户看到自己按下的命令，动作立刻有结果，例如猫标睁眼、JSON 窗口出现）。失败也不靠 002，而是「面板不关、就地 alert」（§6.3）。002 的提示服务于面板之外的另外两条路径：⌃⌥⌘K／⌃⌥⌘J 全局快捷键，以及 `cubbix://awake`——它们都没有别的可见结果 |
| 反馈设置（002 的 `FeedbackMode`） | 面板不读这个设置：面板不是提示。 |
| 快捷键冲突 | 三个快捷键（常亮、JSON、面板）互斥，冲突提示复用 `JSONShortcutConflict`／新增 `PaletteShortcutSuffix`（§2.4）。 |
| 设置页 | 面板的录制行加在 002 新增的两行之前还是之后：002 的两行（反馈方式、提示位置）排在三个录制行之后，即「常亮／JSON／命令面板／反馈方式／提示位置」。`settingsHeight` 按行数计算（§2.4），两个规格谁先落地都能自洽。 |
| 设计稿 | 003 的 R09 画板与 002 的 R08 画板互不覆盖；R09 只画命令面板与动作列表（浅深 × 中英），设置页第三行录制在 R09 里画「快捷键页 3 行」一版，若 002 同时落地则按 5 行重画。 |
