## 结论摘要

| 项 | 结论 |
| --- | --- |
| 入口分工 | 点菜单栏猫标 → 卡片面板（001，看状态、点高频操作）；卡片底部保留命令面板图标（调 `showPalette`）；全局快捷键 → 命令面板（键盘做完一切）。两个面板互斥（§9） |
| 默认快捷键 | `Alt+.`（⌥.），可在设置「快捷键」页录制修改；注册后 `≥` 无法输入，作为已知取舍（§2.4） |
| 面板性质 | 独立 `Panel` 窗口。「不激活应用」「不切 Space」有源码依据；「能输入文字」「中文输入法」「系统阴影」未实测；`Regular` 状态下能否盖住别人的全屏未证实。Esc／失焦／执行后自动收起 |
| 命令模型 | `command{ID, Title, Keywords, Tile, Icon, Param, Available, Run, Actions}`；标题一律走 `application.text`；常亮、JSON 各自注册，通用命令由应用注册（§2） |
| 搜索 | 分组「收藏／最近使用／全部命令」；命令前缀整段匹配 + 参数切分；共享关键词且无参数时回退到普通搜索，`json` 默认选中 `json.new`（§3） |
| 参数 | `45m`、`1h30m`、`until 18:30`、`∞`；整段匹配，组合式先于单独小时／分钟；非法时搜索框右端 alert 图标 + tooltip，回车不执行（§4） |
| Actions | ⌘K 打开动作列表（仅保持任务、30 分钟…、直到某时刻…、关闭、置顶、加入收藏），同列替换命令列表（§5） |
| 视觉 | 640 × 400，圆角 12，`ColorMenuSurface` 表面，行高 36；只用既有 Token 加 6 个新尺寸 Token（§7） |
| URL scheme | `cubbix://awake?minutes=60&mode=tasks`、`cubbix://awake/stop`、`cubbix://json/new`、`cubbix://palette`（+ 建议的 `awake/toggle`、`settings`）；白名单 + 参数校验，`json/new` 只开空白文档或写入 `text` 正文，绝不读剪贴板、不执行任意代码（§8） |
| 与 002 的关系 | 面板内执行成功不弹屏幕提示；失败时面板不关、就地显示 alert。URL 与全局快捷键路径仍走 002 的提示，URL 的文案读本次请求参数，不读记忆设置（§9） |
| MyGo 能力 | 「Panel 可成为 key window 且显示时不激活应用」有文档、源码与框架自带 e2e 断言（网页 input）三方面依据；原生 UI 文本输入、中文输入法、系统阴影、菜单栏点击不收起均为「未实测」，替代方案见 §6.5 |

## 1. 使用场景与键盘路径

### 1.1 与卡片面板（001）的分工

| | 卡片面板（001） | 命令面板（003） |
| --- | --- | --- |
| 打开方式 | 点菜单栏猫标；卡片底部命令面板图标调 `showPalette` | 全局快捷键 ⌥.（或 `cubbix://palette`） |
| 主要用途 | 看状态（剩余时间、进程、窗口列表）+ 单点高频操作 | 不用鼠标、一次做完任何操作 |
| 输入 | 鼠标为主，Tab 可遍历 | 键盘唯一必需 |
| 低频入口 | **没有**自定义时长、直到某时刻、跟随进程的入口（只保留状态行） | 这三个参数的唯一入口（`awake.custom`／`awake.until`／`awake.follow`） |
| 生命周期 | 点外部收起 | Esc／失焦／执行后收起，常驻内存但默认不可见 |

两者不互相替代：001 的菜单栏面板保留「看」的价值（常亮剩余时间、JSON 窗口列表），命令面板不重复显示这些状态（低信息密度，§7.4）。同一个动作在两个入口里必须落到同一个函数，避免出现两套语义（§2.5 的接入表）。

两个面板**互斥**，同一时刻最多一个可见：

- 点猫标：先 `hidePalette()`，再显示卡片面板（不依赖失焦，菜单栏点击未必让 key window 失焦，§6.4 第 8 项）。
- 按 ⌥.：卡片面板开着时先收起卡片，再 `togglePalette()`（001 §3.6 同一条要求）。
- 面板内打开设置、新建 JSON 窗口等会激活应用的窗口时，命令面板靠失焦自动收起；卡片面板同理。

### 1.2 操作清单与键盘路径

`⌥.` = 呼出面板，`↩` = 回车执行，`⌘K` = 动作列表，`esc` = 收起。下表「键盘路径」一列都在面板内完成，不含鼠标。

| 5 | 一直开到某个时刻 | 每周数次 | ⌥. → `常亮 until 18:30` → ↩ | 3 |
| 6 | 不限时开常亮 | 每周数次 | ⌥. → `常亮 ∞` → ↩ | 3 |
| 7 | 新建 JSON 窗口（自动读剪贴板） | 每天多次 | ⌥. → `json` → ↩（或既有 ⌃⌥⌘J） | 3 |

补充规则：

- 面板内**不显示**常亮剩余时间、JSON 窗口内容摘要等状态；想看状态就点猫标（001）。
- 已经在用 ⌃⌥⌘K／⌃⌥⌘J 的人不需要改用面板：两个全局快捷键保持原样（`awake_app.go` 的 `registerAwakeShortcut`，约 102 行；`json_app.go` 的 `registerJSONShortcut`，约 54 行）。
- 面板执行失败时**不收起**（§6.2），失败信息就地显示，用户可以直接改参数重试。

### 1.3 为什么是 ⌥.

| 候选 | 冲突情况 | 结论 |
| --- | --- | --- |
| `⌥.`（Alt+Period） | 系统与常见应用未占用；Carbon 热键表里有 `.`（`mygo@v0.6.2/internal/darwin/hotkey.go` 的键码表，约 29 行；`.` = `0x2F`） | **采用** |
| `⌘Space`、`⌃Space`、`⌥Space` | 输入法切换、Spotlight、Raycast 等第三方启动器 | 不用，已写进系统冲突表（`awake_view.go` 的 `knownShortcutConflict`，约 308 行） |
| `⌃⌥⌘K`／`⌃⌥⌘J` | 已给常亮与 JSON 使用（`config.go` 的 `defaultConfig`，约 36 行） | 不重复占用 |
| `⌘,` | 设置窗口（`main.go` 的 `applicationMenu`，约 257 行） | 不用 |

已知取舍：美式键盘上 `⌥.` 输入 `≥`。全局热键由 `RegisterEventHotKey` 注册（`mygo@v0.6.2/internal/darwin/hotkey.go`，约 58 行），注册后这次按键不再交给前台应用，`≥` 也就打不出来——这是 Carbon 热键的行为语义，**本机未实测**（§6.4 第 12 项），验收时会确认。它属于用户可自行改掉的默认值，不在应用里做例外处理；改动只走设置页录制（§2.4）。需要输入 `≥` 时，可用输入法面板或字符检视器，也可以在设置里把面板快捷键改成其他组合。

## 2. 命令模型

### 2.1 数据结构（只给签名，不给实现）

新文件 `commands.go`：

```go
// 参数类型。目前只有常亮需要参数，新增参数类型时在这里扩展。
type commandParam int

const (
	paramNone        commandParam = iota // 不接受参数
	paramAwake                            // 常亮：时长 / 直到 / 不限时 / 用记忆设置
)

// 一条命令。命令是纯数据 + 函数字段，不持有窗口。
type command struct {
	ID        string                                     // 稳定标识，用于收藏、最近使用与 URL 路由，如 "awake.start"
	Title     func(a *application, locale string) string  // 列表标题；静态命令用 localizedTitle("R05Start")
	Keywords  []string                                   // 可搜索的别名与关键词（手写，含拼音全拼与首字母）
	Tile      string                                     // "awake" / "json" / ""（通用）；仅用于分组图标与归属
	Icon      string                                     // Lucide 文件名，见 §7.2
	Param     commandParam                               // 参数类型
	Available func(a *application) bool                   // 可用条件，nil 表示恒可用
	Run       func(a *application, req request) error
	Actions   func(a *application, req request) []paletteAction
}

// 一次执行请求。Arg 是命令前缀之后的原文，Awake 是解析结果。
type request struct {
	Command *command
	Arg     string   // 未解析的原文，例如 "1h30m"、"until 18:30"
	Awake   awakeArg // Param == paramAwake 时的解析结果
}

// 动作列表里的一项（⌘K 打开）。
type paletteAction struct {
	ID        string                                     // 稳定标识，如 "awake.start.tasks"
	Title     func(a *application, locale string) string
	Icon      string                                     // 空表示不画图标
	Group     int                                        // 0 主操作、1 参数、2 组织（收藏）
	Checked   func(a *application) bool                   // 单选态（模式、时长），nil 表示不是单选
	Available func(a *application) bool
	Run       func(a *application) error
}

// localizedTitle 把资源键包成标题函数。标题必须经 application.text 取词，
// 不能把资源键原样贴到界面上（staticTitle 那类写法会把 "R05Start" 直接显示出来）。
func localizedTitle(key string) func(a *application, locale string) string {
	return func(a *application, locale string) string { return a.text(locale, key) }
}
```

`awakeArg`（`commands.go`，与 §4 的语法一一对应）：

```go
type awakeArgKind int

const (
	awakeArgDefault   awakeArgKind = iota // 用记忆设置（a.selectedSession()）
	awakeArgMinutes                       // 固定分钟数
	awakeArgUntil                         // 直到某时刻
	awakeArgUnlimited                     // 不限时
)

type awakeArg struct {
	Kind    awakeArgKind
	Minutes int    // awakeArgMinutes
	Until   string // awakeArgUntil，"18:30"
	Error   string // 非空表示非法，值是资源键（DurationError / TimeError）
}
```

### 2.2 注册表

```go
// commands.go
func (a *application) commands() []*command      // 每次显示面板时组装：常亮 + 已打开的 JSON 窗口 + 通用
func (a *application) awakeCommands() []*command
func (a *application) jsonCommands() []*command  // 依赖 a.jsonDocuments，动态生成
func (a *application) systemCommands() []*command
```

规则：

- 注册表**不做全局单例**，每次 `showPalette()` 现算一次。JSON 窗口会随时增减，缓存反而要处理失效。
- `Available` 在组装时求值一次即可（面板是临时浮层，显示期间不刷新列表）；不在 `Available` 里做耗时工作。
- 命令顺序即列表里的稳定顺序（用于打分相同时的次序）：常亮 → JSON → 通用。

| `update.restart` | `MenuRestartUpdate` 重启以完成更新 | `重启`、`restart`、`chongqi` | `refresh-cw` | `paramNone` | `update.Phase == updateReady` | `a.restartUpdate()` |
| `app.quit` | `Quit` 退出 Cubbix | `退出`、`quit`、`tuichu`、`tc` | `power` | `paramNone` | 恒可用 | `mygo.App.Quit()` |

说明：

- `settings.page` 是四条独立命令（通用／格子／快捷键／关于），共用 `settings.page` 前缀 ID + 页名后缀，例如 `settings.page.shortcuts`；这样收藏「快捷键设置」是稳定的一项，而不是一条带参数的命令。页码沿用 `a.page` 的既有取值：通用 0、关于 1、格子 2、快捷键 3（`main.go` 的 `view` 里导航顺序为 `[]int{0, 2, 3, 1}`，约 463 行）。
- `json.window` 的标题来自文档名，属于**动态标题**；ID 用文档自带的序号：`json.window.<jsonDocument.number>`。`number` 由 `addJSONDocument` 分配（`json_documents.go`，约 46 行），单调递增且不复用，窗口关掉后旧 ID 自然消失。**不要用切片下标**：`removeJSONDocument`（`json_documents.go`，约 53 行）会移位。
- JSON 窗口命令**不进收藏、不进最近使用**（§3.1），因为它们在文档关闭后即失效。
- 常亮的模式分段器保留在卡片面板；**自定义时长、直到某时刻、跟随进程只在命令面板**，卡片面板没有入口（只有状态行会显示这类会话）。语义必须与 `a.setMode`（`awake_app.go`，约 75 行）、`a.openAwakeDialog`（`awake_view.go`，约 33 行）完全一致，不允许复制实现。
- `json.new` 的默认执行是「从剪贴板新建」（`a.newJSONWindow`），同时提供「新建空白窗口」动作。**读剪贴板只属于面板**；URL 走 `addJSONDocument(text, "", true)`，不碰剪贴板（§8.3）。

### 2.4 配置与快捷键

`config.go` 的 `Config`（约 14 行）新增三个字段，放在 `AwakeShortcut` 之后：

| 字段 | TOML 键 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `PaletteShortcut` | `palette_shortcut` | string | `Alt+.` | 面板全局快捷键 |
| `PaletteFavorites` | `palette_favorites` | []string | 空 | 收藏的命令 ID，按收藏顺序 |
| `PaletteRecents` | `palette_recents` | []string | 空 | 最近执行，最多 5 条，最新在前 |

实现要点：

### 3.1 分组

| --- | --- | --- | --- |

规则：

- 同一条命令只出现一次：先进收藏，再进最近使用，最后进全部。
- 输入关键词后**保留分组**，每组只显示命中的行；空组连标题一起隐藏。这样「收藏里的命令永远在同一个位置」，比打散重排更好记。
- 收藏与最近使用不包含 `json.window.*`（§2.3）。
- 分组标题不占选中位置：`ui.ListState.Header`（`mygo@v0.6.2/ui/list.go` 的 `ListState.Header`，约 93 行）标记标题行，上下移动时跳过。

### 3.2 命令前缀与参数切分

面板输入框里只有一行文本，面板要自己判断「哪部分是命令、哪部分是参数」。规则按顺序执行：

1. 规范化：`strings.TrimSpace`，连续空白折成一个空格，其余原样（中文不用转小写，比对时对 ASCII 部分做 `strings.ToLower`）。
2. **前缀匹配（整段）**：对每条命令的搜索名（标题 + 每个 `Keywords`）检查，只有三种情况算命中：
   - 输入等于该名；
   - 输入以「该名 + 空白」开头；
   - 该名后紧接一个**非字母字符**（数字、`∞`、`:`、`-`、`+`）。
   命中者里取名字最长的一个，其余部分整体作为参数原文；名字等长时按 §2.2 的注册顺序取靠前者（`json.new` 在 `json.window` 之前）。
   - `常亮 1h` → `awake.start`，参数 `1h`
   - `常亮1h` → 同上（中文输入法下用户常常不打空格）
   - `常亮` → `awake.start`，参数为空
   - `json items.json` → 前缀 `json`，余下 `items.json`；因为 `json.*` 都是 `paramNone`，余下部分不回退成参数，而是整行当查询，列表收窄（§3.3）
3. **参数只给 `Param != paramNone` 的命令**：命中命令的 `Param == paramAwake` 时，参数原文整段交给 `parseAwakeArg`（§4）；解析失败就按 §4.2 显示 alert，**不退回整行搜索**（`常亮 45x` 是错误态，不是空结果）。`Param == paramNone` 时余下部分不参与执行，只参与搜索。
4. **没有前缀命中**：整行当作查询词，只做搜索（§3.3），不产生参数。

`常亮开关` 不会命中前缀：`常亮` 后面紧接的是汉字（字母），不满足上面的三种情况，因此整行当查询词。这正是之前「退回整行搜索」想解决的场景，改写进前缀规则后不需要额外的回退分支。

**共享关键词且无参数**：多条命令共用同一个名字（`json` 同时是 `json.new` 与 `json.window` 的关键词）且余下为空时，不直接执行、也不弹错误，而是走普通搜索，并把**注册顺序最靠前的命中行设为默认选中**（这里不看 §3.3 的「标题短优先」，否则默认行会随文档名变化）。因此输入 `json` 回车就是 `json.new`（新建 JSON 窗口，§1.2 第 7 条），想要别的行用 ↑／↓ 或继续输入。

### 3.3 模糊匹配与排序

打分函数（纯函数，`commands.go` 内，单元测试覆盖）：

```go
// matchScore 返回最佳匹配得分；0 分表示不命中。
func matchScore(query, title string, keywords []string) int
```

| 层级 | 条件 | 得分 |
| --- | --- | --- |
| 1 | 标题完全相等 | 1000 |
| 2 | 标题以查询开头 | 900 − len(title) |
| 3 | 某关键词完全相等 | 800 |
| 4 | 某关键词以查询开头 | 700 − len(keyword) |
| 5 | 标题包含查询（子串，CJK 主要走这里） | 600 − 命中位置 |
| 6 | 关键词包含查询 | 500 − 命中位置 |
| 7 | 标题构成子序列 | 400 − 2 × 跳过的字符数 |
| 8 | 关键词构成子序列 | 300 − 2 × 跳过的字符数 |

- 大小写不敏感；空格分隔的多词查询按「每个词都必须命中」处理，总分取各词得分的和。
- 同分时的次序：标题更短者优先，再按 §2.2 的注册顺序（稳定排序，保证同一查询每次结果一致）。
- 子序列匹配只用于 ASCII（`jsonw` → `json.new`、`cl` → 常亮）；中文标题用子串匹配，避免出现「常亮」被拆成无意义单字命中。
- 不使用编辑距离（Levenshtein）：命令总数不到 20，纠错收益低，反而会让「1 个字之差」的误命中把正确项挤下去。

### 3.4 拼音：推荐不做拼音库，改为手写关键词

| 方案 | 代价 | 结论 |
| --- | --- | --- |
| 引入拼音库（映射表或 GBK 编码表） | 新依赖 + 数据表体积；AGENTS 要求固定版本、不从网络加载 | 不选 |
| 手写 `Keywords`（含全拼与首字母） | 每条命令 2–4 个词，十几条命令一次写完；漏写可用测试兜住 | **采用** |
| 完全不做拼音 | 中文用户输入 `cl` 找不到常亮，只能打中文 | 不选 |

因此 §2.3 的 `Keywords` 列里已经写好全拼（`changliang`）与首字母（`cl`）。配套测试：每条命令的 `Keywords` 至少 1 个；除归属词外全局不重复。归属词指 `json` 这种「同类命令共享的词」，允许同时出现在 `json.new` 与 `json.window` 上，测试按「同一 `Tile` 内最多共享一个词」实现。

## 4. 参数输入

### 4.1 语法

只对 `paramAwake` 生效。解析函数 `parseAwakeArg(arg string, now time.Time) awakeArg`，输入是前缀切分后的整段原文（已 Trim，未做其它改写）。**每一行都要求整段匹配**，不允许从字符串中间找子串；全部大小写不敏感。下表顺序即匹配优先级：

| 写法 | 结果 | 说明 |
| --- | --- | --- |
| 空 | `awakeArgDefault` | 用记忆设置：`a.selectedSession()` 会读 `config.AwakeMinutes`／`AwakeUntil`／`AwakeMode` |
| `∞`、`inf`、`infinity`、`unlimited`、`无限`、`不限`、`不限时`、`0` | `awakeArgUnlimited` | 与 `config.AwakeMinutes == 0` 同义（`awake_app.go` 的 `selectedSession`，约 47 行） |
| `until 18:30`、`到 18:30`、`直到 18:30`、`18:30` | `awakeArgUntil{Until:"18:30"}` | 只接受 24 小时制 `H:MM`／`HH:MM`，整段交给与 `confirmAwakeDialog` 相同的 `untilTime`（`keepawake.go`，约 182 行）校验，不另写一套解析 |
| `1h30m`、`1h30`、`1h 30m`、`1小时30分钟` | `awakeArgMinutes{90}` | **组合式排在单独小时／分钟之前**；中间的空格忽略，但前后不能有多余字符 |
| `45m`、`45min`、`45分钟`、`45 分` | `awakeArgMinutes{45}` | 单独分钟 |
| `2h`、`2小时`、`2 hour`、`2hours` | `awakeArgMinutes{120}` | 单独小时 |
| `45` | `awakeArgMinutes{45}` | 裸数字 = 分钟（见 §10 待决定 4），整段纯数字 |

| `awakeArgMinutes` | 预设四档用既有键，其余用 `PaletteMinutes`（`%d 分钟`／`%d min`） |
| `awakeArgUntil` | `PaletteAwakeUntil`（`直到 %s`／`Until %s`） |
| `awakeArgUnlimited` | `R05Unlimited` |
| 其它命令 | 不显示 hint（`paramNone`），保持空白 |

hint 只讲时长，不讲模式：模式由 ⌘K 动作里的单选态表示（§5.2），避免一格里塞两段信息。

## 5. Actions（⌘K）

### 5.1 交互形态

| 步骤 | 行为 |
| --- | --- |
| ⌘K（列表模式下） | 切换到动作列表：命令列表被替换，顶部多一行命令标题（图标 + 标题），下接当前命令的动作 |
| ⌘K（动作模式下） | 回到命令列表，保留原来的查询与选中行 |
| Esc（动作模式下） | 回到命令列表（不是收起面板）；命令列表下 Esc 才收起 |
| ↑／↓ | 在动作间移动（跳过不可用项） |
| ↩ | 执行选中的动作 |
| 点击 | 执行（与键盘等效） |

采用**同列替换**而不是 Raycast 的双列：双列需要列表列宽度在打开动作时改变，原生 UI 里会让每一行重新排版一次，视觉跳动比收益明显；同列替换不改变任何几何。

### 5.2 各命令的动作

| 命令 | Group 0 主操作 | Group 1 参数／状态 | Group 2 组织 |
| --- | --- | --- | --- |
| `awake.start` | `awake.start.screen` 保持屏幕常亮开启／`awake.start.tasks` 仅保持任务开启（两个都显示，`Checked` 标出 `config.AwakeMode`） | `R05Half`、`R05Hour`、`R05Two`、`R05Four`、`R05Unlimited`（五个都显示，`Checked` 标出与输入参数一致的项）；`R05Until`、`R05Custom`、`R05Follow`（打开既有小窗 `openAwakeDialog`） | `PaletteAddFavorite`／`PaletteRemoveFavorite` |
| `awake.stop` | — | — | 收藏 |
| `awake.mode.*` | — | — | 收藏 |
| `awake.until`／`awake.custom`／`awake.follow` | — | — | 收藏 |
| `json.new` | `PaletteJSONClipboard` 从剪贴板新建（默认）、`PaletteJSONBlank` 新建空白窗口 | — | 收藏 |
| `json.window` | `PaletteSwitchTo` 切过去（默认） | `R07Pin`／`R07Unpin`（按 `d.pinned` 只显示一个）、`JSONClose` 关闭 | **不提供**（窗口关闭后失效） |
| `settings.*`／`update.*`／`app.quit` | — | — | 收藏 |

要点：

- `awake.start` 的 ⌘K 动作**覆盖输入参数**：输入了 `45m` 再选 `1 小时`，按 1 小时执行。参数是输入框的事，动作是显式选择。
- `awake.start.screen`／`.tasks` 执行时保留输入参数：`常亮 45m` + ⌘K + 仅保持任务 → 45 分钟 + `tasks`。
- 置顶动作要回写 web 端状态：`a.setJSONPinned` 只改 Go 侧 `d.pinned` 与 `SetAlwaysOnTop`，与 bridge 的 `Pin`（`json_app.go`，约 370 行）行为一致；前端在下一次 `Changed`／`Boot` 时拿到新值，不需要面板去 Eval 页面。
- 动作行的 `Icon` 为空时只画标题（例如收藏的移出项与部分关闭项），不强行配图标。

## 6. 窗口行为

### 6.1 创建参数

```go
t := tokens(false, "zh-CN") // 尺寸与颜色与语言、主题无关
w := mygo.NewWindow(mygo.WindowOptions{
	Title:             "Cubbix",
	Width:             int(t.SizePaletteWidth),
	Height:            int(t.SizePaletteHeight),
	Hidden:            true,
	Frameless:         true,
	Transparent:       true,
	DisableResize:     true,
	DisableMove:       true,
	DisableMinimize:   true,
	DisableMaximize:   true,
	DisableFullScreen: true,
	Panel:             true, // 关键：不激活应用的浮层，可成为 key window
	Content:           ui.View(a.paletteView),
})
w.OnClose(func(e *mygo.CloseEvent) { e.PreventDefault(); a.hidePalette() })
w.OnBlur(a.hidePalette)
```

说明：

- `Panel` 会强制 `AlwaysOnTop` 与 `SkipTaskbar`、禁用最小化／最大化／全屏（`mygo@v0.6.2/window.go` 的 `NewWindow` 处理 `Panel` 的分支，约 530 行），不需要另外设置。
- 不设 `DisableClose`：面板没有标题栏与关闭按钮，任何关闭请求（Esc、⌘W、`Window.escape`）都统一由 `OnClose` 拦成隐藏；设了反而多一个未验证的风格位。
- 不用 `SetIgnoreMouseEvents`：面板必须收点击（选行、输入框定位）。
- 不设置 `Vibrancy`：面板表面用 92% 不透明的 `ColorMenuSurface`（§7），比 HUD 毛玻璃在浅色桌面上更清楚，也省掉「有材质时不铺底色」的分支。
- 阴影用系统默认（不设 `DisableShadow`）：MyGo 在 flyout 里的注释说明透明窗口的系统阴影「由窗口绘制的内容生成」，因此跟随自绘圆角（`mygo@v0.6.2/internal/darwin/window.go`，约 251 行）。这一条只对 flyout 有实测记录，面板需要目视确认，见 §6.5 第 5 项。

### 6.2 显示、收起与位置

```go
func (a *application) togglePalette() {
	if a.shortcutRecording { // 录制期间不弹面板，否则会抢走按键
		return
	}
	if a.paletteVisible() {
		a.hidePalette()
		return
	}
	a.hideMenubarPanel() // 两个面板互斥：卡片开着就先收起（001 的收起入口）
	a.showPalette()
}

func (a *application) showPalette() {
	if a.palette == nil {
		a.createPaletteWindow() // 延迟创建：不按快捷键就完全不开窗口
	}
	a.palette.reset()      // query = ""、选中第一行、模式 = 命令列表、错误清空
	a.placePalette()
	a.palette.window.Show() // 不是 ShowInactive：面板必须拿到键盘
}

func (a *application) hidePalette() {
	if a.palette == nil || a.palette.window == nil { return }
	a.palette.window.Hide()
}

func (a *application) placePalette() {
	d := mygo.Screen.DisplayNearestPoint(mygo.Screen.CursorScreenPoint())
	w, h := a.palette.window.Size()
	x := d.WorkArea.X + (d.WorkArea.Width-w)/2
	y := d.WorkArea.Y + int(tokens(false, "zh-CN").SizePaletteTopOffset)
	if y+h > d.WorkArea.Y+d.WorkArea.Height { // 小屏兜底
		y = max(d.WorkArea.Y, d.WorkArea.Y+d.WorkArea.Height-h)
	}
	a.palette.window.SetPosition(x, y)
}
```

| 时机 | 行为 |
| --- | --- |
| 按 ⌥. | 卡片面板开着就先收起卡片；命令面板未显示则显示并按鼠标所在屏幕定位，已显示则收起（同一个键开关） |
| 执行命令 | **先收起面板，再执行**；失败时重新显示并保留查询与错误（§6.3） |
| Esc | 收起（视图注册 `c.OnShortcut(0, ui.KeyEscape, ...)`，同时 `OnClose` 里 `PreventDefault` + 隐藏兜底） |
| ⌘W | 收起（与 Esc 同义，视图注册 `c.OnShortcut(ui.Cmd, ui.KeyW, ...)`） |
| 失焦 | 收起（`OnBlur`，`mygo@v0.6.2/window.go` 的 `Window.OnBlur`，约 1497 行） |
| 点击别的窗口、切换应用、⌘Tab | 上面的失焦即可覆盖 |
| 点猫标 | 卡片回调里**显式**调 `hidePalette()` 再显示卡片，不依赖失焦（菜单栏点击未必让 key window 失焦，§6.4 第 8 项） |
| 点其他菜单栏项目 | 不保证收起（`OnBlur` 覆盖不到）；按实测记录，作为已知缺口（§6.5 第 3 项） |
| 打开设置页、新建 JSON 窗口 | 面板失焦自动收起 |
| 显示器拔掉／分辨率变化 | 显示中时按 §6.2 的 `placePalette` 重算位置（订阅 `Screen.OnDisplaysChanged`，`mygo@v0.6.2/modules.go`，约 306 行），不改变查询与选中行 |
| 退出应用 | `beforeQuit`（`main.go`，约 379 行）里隐藏面板窗口；`GlobalShortcut.UnregisterAll()` 已经覆盖快捷键 |
| 录制快捷键期间 | `togglePalette` 直接返回（§2.4） |

**绝不能做的事**（都会把面板变成「会切 Space 的窗口」或抢走前台）：

1. 不调用 `a.visibility(true)`（`main.go` 的 `visibility`，约 175 行）——它会把激活策略切成 `Regular`，MyGo 在策略变成 regular 时会 `activateIgnoringOtherApps:`（`mygo@v0.6.2/internal/darwin/app.go` 的激活策略分支，约 370 行）。
2. 不调用 `mygo.App.SetActivationPolicy`、`mygo.App.Activate()`。
3. 不用 `ShowInactive`：它只 `orderFrontRegardless`，不成为 key window（`mygo@v0.6.2/internal/darwin/window.go` 的 `ShowInactive`，约 755 行），面板收不到键盘。
4. 不在视图里用 `Hidden` 开关代替 `Hide()`。

`main.go` 的 `OnActivate` 回调（约 329 行）目前是「没有任何可见窗口就打开设置」。面板是 tool window，不进入这套判断；为避免用户在面板可见时误触激活（例如 Spotlight 打开 Cubbix），回调里加一行：面板可见时先收起面板再返回，不打开设置窗口。

### 6.3 焦点、Esc 与执行结果

| 主题 | 结论 |
| --- | --- |
| 输入框焦点 | 输入框用固定的 `Key` + `Element.Focus()`（每帧调用即持续持有焦点，`mygo@v0.6.2/ui/api_gen.go` 的 `Focus`，约 3754 行），而不是只用 `AutoFocus`（只在元素首次出现的帧生效，同文件约 2782 行）；这样面板隐藏再显示时焦点自动回到输入框。只有画「参数错误」的 alert 图标时才让它可聚焦，仍不抢输入框焦点 |

| ↩ | 输入框 `OnSubmit`（`mygo@v0.6.2/ui/actions.go` 的 `OnSubmit`，约 43 行）+ 视图根上的 `OverlayShortcut(0, ui.KeyEnter)` 兜底（输入法组合中不触发，见下） |

| Esc 的传递链 | 视图没接管的 Esc 会经 `ui/engine.settleKeys` 交给宿主（`mygo@v0.6.2/ui/input.go`，约 903 行），`Window.escape` 对 panel 直接 `close()`（`mygo@v0.6.2/flyout.go`，约 241 行），因此 `OnClose` 必须 `PreventDefault` 并改为隐藏 |
| 执行成功 | 收起面板；不弹任何提示（§9） |
| 执行失败 | 面板**不关**：`paletteState.errorKey` 记错误键，视图在对应行右侧画 `triangle-alert` + tooltip，`Invalidate()` 重画 |

## 7. 视觉

## 8. URL scheme

### 8.1 路径与参数

Scheme 固定 `cubbix`。解析后 `u.Host` 是动作名，`u.Path` 是子动作，其余走 query。

| URL | 行为 | 参数 |
| --- | --- | --- |
| `cubbix://awake?minutes=60&mode=tasks` | 开启常亮（不写记忆时长／截止） | `minutes`：0–525659 的整数，`0` 表示不限时；`mode`：`screen`／`tasks`。两者都可省：省 `minutes` 读记忆时长／截止，省 `mode` 读 `config.AwakeMode`；但**只读不写**，也不调用 `setDuration`。`awakeChanged` 仍会按既有逻辑写 `AwakeSession`（恢复记录，不是记忆默认值） |
| `cubbix://awake/stop` | 停止常亮 | 无 |
| `cubbix://awake/toggle` | 开／关切换（等价于 ⌃⌥⌘K，`awake_app.go` 的 `toggleAwake`，约 65 行） | 无 |
| `cubbix://json/new` | 新建 JSON 窗口：**只开空白文档**，带的 `text` 作为正文 | `text=`（URL 编码，长度 ≤ `jsonFileLimit`，即 64 MiB，`json_documents.go` 约 15 行）；`blank=1` 表示空白文档。两者并存时用 `text`。**绝不读剪贴板** |
| `cubbix://palette` | 打开命令面板 | 无（等价于 ⌥.；面板会拿键盘但不激活应用） |
| `cubbix://settings?page=general\|tiles\|shortcuts\|about` | 打开设置的某一页 | `page` 非法或缺失时落到「通用」页（`a.page == 0`）；不抄「关于」菜单项的 `a.page = 1`（`main.go` 的 `applicationMenu`，约 256 行） |

工作单点名了 `awake`、`awake/stop`、`json/new`、`palette` 四条；`awake/toggle` 与 `settings` 是本规格**建议补充**的两条，理由见 §10 待决定 5。

### 8.2 注册与送达

| 环节 | 做法 | 依据 |
| --- | --- | --- |
| 声明 scheme | `mygo.json` 增加 `"urlSchemes": ["cubbix"]`（该文件当前没有这个键） | macOS 只把 Info.plist 里 `CFBundleURLTypes` 声明的 scheme 交给应用（`mygo@v0.6.2/docs/app.md`，约 127 行；`mygo@v0.6.2/internal/darwin/deeplink.go`，约 12 行） |
| 成为默认处理者 | 启动时 `mygo.App.RegisterURLScheme("cubbix")`，失败只记日志、不阻塞启动 | `mygo@v0.6.2/deeplink.go` 的 `RegisterURLScheme`，约 147 行；macOS 上未声明时返回错误（`internal/darwin/deeplink.go`，约 20 行），已声明时调 `LSSetDefaultHandlerForURLScheme`（同文件约 24 行） |
| 接收 URL | `mygo.App.OnOpenURL(func(raw string){ a.handleURL(raw) })`，**在 `App.Run` 之前注册**，这样「用 URL 启动应用」的那一次也能收到 | `mygo@v0.6.2/app.go` 的 `OnOpenURL`，约 460 行；`docs/app.md` 约 127 行；启动参数由 `launchArgs` 在 ready 之后投递（`mygo@v0.6.2/deeplink.go`，约 189 行） |

| 回调线程 | 实现时统一 `mygo.RunOnMain`，不赌调用线程 | 全局快捷键的回调在主线程（`mygo@v0.6.2/docs/native.md` 的 Global shortcuts 一节）；`OnOpenURL` 也来自主线程（AppKit 的 `application:openURLs:`，`mygo@v0.6.2/internal/darwin/app.go`，约 326 行；启动时由主线程的 `launchArgs` 投递，`mygo@v0.6.2/deeplink.go`，约 189 行） |

`cubbix://palette` 会显示面板并拿到键盘（与 ⌥. 等价），这是唯一一条会「抢键盘」的 URL；其余 URL 不显示任何窗口（`json/new` 与 `settings` 本来就会打开各自窗口，属于它们自己的既有语义）。

### 8.3 校验与安全

URL 来自任何应用或网页（scheme 一旦声明就对系统全局有效），按**不可信输入**处理：

1. `url.Parse` 失败 → 丢弃。`u.Scheme` 必须等于 `cubbix`（大小写不敏感）。
2. **大小写折叠与去斜杠**：`u.Host` 转小写、去掉首尾的 `/`；`u.Path` 转小写、去掉首尾的 `/`。折叠后再查白名单。
3. 折叠后的 `u.Host` 必须在 `{awake, json, palette, settings}` 里；折叠后的 `u.Path` 按父动作校验：`awake` 只接受空、`stop`、`toggle`；`json` 只接受 `new`；`palette` 与 `settings` 只接受空。其余一律丢弃。
4. `minutes`：`strconv.Atoi`，必须 `0 ≤ n ≤ 525659`；不是整数或越界 → 整个请求丢弃（不做部分执行）。
5. `mode`：只接受 `screen`／`tasks`，其他值 → 整个请求丢弃。
6. `text` 与 `blank`：`text` 长度 > `jsonFileLimit`（`json_documents.go`，约 15 行，64 MiB）→ 丢弃；`text` 只当文档正文，不当作路径。`text` 与 `blank` 并存时**以 `text` 为准**；两者都没有就开空白文档。
7. **`json/new` 的执行路径（硬约束）**：只能用 `a.addJSONDocument(text, "", true)`（`json_documents.go` 的 `addJSONDocument`，约 46 行）+ `a.createJSONWindow(d)`（`json_app.go`，约 91 行）+ `a.showJSON(d)`。**禁止**调用 `newJSONWindow`／`newJSONDocumentFromClipboard`（剪贴板），**禁止**进入 `window.cubbix.evaluate` 或任何 `new Function`／Eval 路径（`frontend/src/main.js`、`frontend/src/worker.js` 的 `this` 入口）。
8. **`awake` 的执行路径（硬约束）**：用请求参数组装 `awakeSession`，再 `err := a.startAwake(s)`；**不调用 `setDuration`**、不写 `config.AwakeMinutes`／`AwakeUntil`／`AwakeMode`（`awakeChanged` 对 `AwakeSession` 的恢复记录属于既有行为，不在此列）。`minutes` 是显式参数时：0 → `End` 留零值（不限时），否则 `End = time.Now().Add(minutes * time.Minute)`；`minutes` 缺省时按记忆值组装 `End`（`AwakeUntil` 非空走 `untilTime`，否则 `AwakeMinutes`）。`mode` 缺省时取 `a.config.AwakeMode`。
9. 可用性：`awake*` 在 `config.AwakeEnabled == false` 时丢弃；`json/new` 在 `config.JSONEnabled == false` 时丢弃。
10. **不做的事**：不接受文件路径、不读任意文件、不读剪贴板、不执行 JS／`Eval`、不改记忆默认值（`AwakeMinutes`／`AwakeUntil`／`AwakeMode`）、不打开任意 URL、不注册新快捷键。
11. 未知 query 参数忽略；重复参数取第一个（`url.Values.Get` 的行为）。
12. 幂等与限流：同一 URL 连续到达时按普通请求处理（`awake` 重复开启等价于重置时长），不加队列也不报错。

`cubbix://awake` 的屏幕提示仍走 002，但文案必须读**本次请求**（`End`、`minutes`、`mode`），不读 `config.AwakeMinutes`／`AwakeUntil`（§9）；否则用户记忆的是 45 分钟时会被告知「45 分钟」，与实际开的 60 分钟不符。

## 9. 与 001、002 的关系

| 关系 | 结论 |
| --- | --- |
| 与 001（卡片面板） | 两者共用同一批动作函数（§2.5），不各自实现。**入口分工**：自定义时长、直到某时刻、跟随进程**只在命令面板**，卡片面板没有入口，只保留模式分段器、预设时长药丸和状态行（实现见 001 第四轮）。**底部图标**：按 001 第四轮的推荐保留命令面板图标，tooltip 为「命令面板 (⌥.)」，点击调 `showPalette`（不叫 `openCommandPanel`）。**互斥**：点猫标时先 `hidePalette()` 再显示卡片；按 ⌥. 时先调 001 的卡片收起入口（`hideMenubarPanel`）再 `togglePalette()`。不依赖「菜单栏点击会不会让 key window 失焦」这个未实测行为（§6.4 第 8 项） |
