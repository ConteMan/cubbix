## 1. 同类产品怎么把结果交到手上

本节只写交互路径：怎么触发、输入在哪、结果出现在哪、怎么拿走、中间有几步。功能名单不展开。Raycast 手册和 uTools 文档没有直接打开成功，这两处的键位以检索摘要为准；摘要里丢失的键位符号标「未证实」。其它结论来自下列链接的公开页面。没有在本机安装或打开这些应用。

### 1.1 各家的路径

**Raycast 内置计算器**

- 触发：根搜索里直接打，没有单独的「打开工具」这一步。[手册](https://manual.raycast.com/calculator) 写它能算时区、单位、日期和货币，日期可以写成 ISO 8601 的 Zulu，也可以写成 `time in brisbane + 4 hours`（跨夏令时仍留在那个城市）和 `August 5 + 5`。手册的内置例子里没有裸的 Unix 时间戳。

### 1.2 共识、差异、以及用在 Cubbix 的哪一层

共识是一条一步路径：输入或选中已经就绪，结果行或预览出现，回车（或点击）复制。粘贴到前台是第二动作，Raycast 的 `Action.Paste`、Alfred DevToolbox 的 ⌘↩ 都是这样，不是每个内置功能的默认键。

零步只出现在「这次唤出就是对着选中文字或剪贴板」的时候：uTools 超级面板、DevUtils 的检查热键、He3 复制后的推荐。它不适合每一次都从空查询开始的命令面板。`showPalette` 打开时把 `query` 置空；若每次打开都去读选中文字，辅助功能那次读取会挡在输入前面。010 已把划词放在快捷键路径上，命令面板不读。本规格沿用这条边界。

差异：

| 产品 | 裸 Unix 时间戳 | 结果出现的位置 | 拿走结果 |
| --- | --- | --- | --- |
| Raycast 内置 | 手册例子里没有 | 根搜索的答案 | ↵ 复制；粘到前台未证实 |
| uTools / DevUtils / He3 | 有，常靠剪贴板进入 | 超级面板、工具页或搜索预览 | 点击或回车复制 |
| DevToys / Boop | 有 | 窗口或草稿纸 | 生成或变换之后再复制 |

Cubbix 已经有命令面板和工具窗口，对应关系：

- 一步放在命令面板：整段查询命中就换成结果行，回车复制。不先打开一个窗口。
- 零步只做成「空查询时的剪贴板建议」，而且默认不选中。误判一个 10 位数字时，回车仍执行原来的第一条命令，不会把剪贴板抄出去。
- 反复换算、批量 UUID、要记住的大小写和去横线，放进工具窗口。窗口不是主路径。
- ⌘回车粘到前台是第二动作，与 Alfred 的 ⌘↩ 同级，不作为回车的默认。

## 2. 范围

### 2.1 第一批

1. 时间戳与日期互转。单位是秒、毫秒、微秒、纳秒。本地时区与 UTC。ISO 8601 / RFC3339。当前时间。
2. UUID：生成 v4 与 v7；解析粘进来的 UUID，并标出版本半字节和变体。可选大写、去横线、批量。

两件事共用同一套「结果行」。后面若要加 Base64 之类，加的是识别器，不是另一套面板。

### 2.2 第一批不做

| 工具 | 为什么留到后面 |
| --- | --- |
| Base64、URL 编解码 | 和结果行同构，但填充、换行、`+` / `%` 的误判比时间戳多 |
| MD5、SHA-256 | 标准库就能算，但结果不可逆，和「换算」放在同一行里容易抄错 |
| JWT 解码 | 只解码、不验证签名，必须单独写清楚；第一批的界面装不下这句警告 |
| 随机字符串 / 密码 | 字符集和长度是一组设置，不适合塞进「只有开关和快捷键」的设置页 |
| 多时区对照 | 要一张时区列表。第一批只有本地和 UTC |

宁少勿多：第 1 步交付之后，时间戳和 UUID 已经能从命令面板复制出去。上面五行都是后续，不进本规格的实现拆分。

### 2.3 库

`go.mod` 没有 uuid 依赖。Go 1.27.1 的标准库有 `package uuid`。同一工具链下 `go doc uuid` 列出 `New`、`NewV4`、`NewV7`、`Parse`、`MustParse`、`Nil`、`Max`。程序直接调用了 `NewV4` 和 `NewV7`，二者都返回 `UUID`（`[16]byte`），不是 `(UUID, error)`。

不使用 `github.com/google/uuid`。标准库已经覆盖 v4、v7 和解析。

`NewV7` 的完整包注释本轮没有读到，**同一毫秒内的单调性未证实**。规格只依赖三件已见到的事：函数存在、版本半字节是 7、变体高两位是 `10`。时间行从 UUID 前 48 位按 RFC 9562 自行取出 Unix 毫秒，不依赖库再提供一个时间函数。同一工具链的另一次运行里，这样取出的毫秒与当时的 UTC 相差 0；本轮这次生成没有再解。

时间只用标准库 `time`。时区用 `time.Local` 与 `time.UTC`，不内置城市表。

### 2.4 仓库外实验（Go 1.27.1，程序已删除）

**UUID `Parse`**

| 输入 | 结果 |
| --- | --- |
| 32 位无横线十六进制 | 成功，输出仍是带横线的标准串 |
| 大写、带横线 | 成功 |
| `{...}` 花括号 | 成功 |
| `urn:uuid:` 前缀 | 成功 |
| 版本半字节为 0 | 成功。`Parse` 不是版本识别器 |
| Nil（全 0） | 成功，变体高两位是 `00` |
| `NewV4` / `NewV7` | 版本半字节分别是 4 和 7，变体高两位都是 `10` |

因此识别必须先看文本形状，再调用 `Parse`。不能把「`Parse` 成功」当成「这是用户想换算的 UUID」。

**时间**

| 输入 | 结果 |
| --- | --- |
| `time.Unix(2147483648, 0)` | `2038-01-19T03:14:08Z`。没有 2038 溢出 |
| `time.Unix(-1, 0)` | `1969-12-31T23:59:59Z` |
| `time.Date(2000, 1, 1, …)` 的 Unix 秒 | `946684800`，9 位 |
| `time.Unix(1000000000, 0)` | `2001-09-09T01:46:40Z`。10 位秒、13 位毫秒都从这一刻起算 |
| `time.Date(2100, 1, 1, …)` 的 Unix 秒 | `4102444800` |
| `2016-12-31T23:59:60Z` | `Parse` 报 `second out of range` |
| 纽约 `2026-03-08 02:30:00` | `ParseInLocation` **不报错**，得到 `2026-03-08T01:30:00-05:00`。跳空被折进跳空前的钟面 |
| 纽约 `2026-11-01 01:30:00` | `ParseInLocation` 得到 `2026-11-01T01:30:00-04:00`（第一次，EDT） |
| 上一条再 `Add(time.Hour)` | 钟面仍是 `01:30:00`，偏移变成 `-05:00`。第二次存在 |
| `2006-01-02 15:04:05` 这个版式 | 对同一秒上的 500 ms 和 999 ms 都停在该秒，没有进到下一秒 |
| 公元 10000 年 | `Format` 返回 `10000-01-01T00:00:00Z`，**不报错** |
| 公元 1 年与 9999-12-31 | 都能格式化。公元 1 年的 Unix 秒是 `-62135596800`，11 位 |

两条直接写进规则的推论：

- 纯位数不能覆盖 2000 年到 2001-09-09。9 位秒、12 位毫秒在裸输入里不自动换算。
- 不能靠 `Format` 的报错来拒绝五位年份。年份 1–9999 是产品规则。

## 3. 交互

识别函数放在 `internal/devtools`，命令面板、窗口和 CLI 调用同一套。它不读剪贴板，不生成 UUID。生成单独一个函数，并且只在查询变化时调用一次。

`refreshPalette` 每帧都跑。结果若在 `refreshPalette` 里调用 `NewV4`，UUID 会每一帧变一次，回车复制到的不是用户看见的那一串。生成结果按查询字符串缓存在 `paletteState` 上，查询没变就复用。`now` 同样只在这次查询开始时取一次 `time.Now()`。

### 3.1 什么时候换成结果行

模块关闭时不识别，面板与现在一样。

模块打开时，在 `refreshPalette` 做普通搜索之前，对去掉首尾空白的整段查询按下面的顺序判断。命中之后列表里只有结果行，不再混入同名词的 JSON 窗口或其它命令。

1. 第一个词是 `ts`、`timestamp` 或 `时间戳`（大小写不敏感）：走时间。没有参数、或参数是 `now`，表示当前时间。其余参数按 §3.2 的「带前缀」规则解析。解析失败是错误行，不退回搜索。
2. 整段就是 `now`：当前时间。
3. 第一个词是 `uuid`、`uuid4`、`uuidv4`、`uuid7`、`uuidv7`：走 UUID 生成。个数规则见 §3.3。`uuid v4` 这种中间再加版本词的写法不接受，整段退回搜索。
4. 整段是 UUID 字面量：解析，不生成。
5. 整段是落在窗口里的裸整数：当时间戳。
6. 整段是日期：当日期。
7. 否则普通搜索。

`devtools`、`开发工具` 不是识别词。它们是一条普通命令，打开空的工具窗口，不生成 UUID。现有命令的 `Keywords` 里没有 `uuid`、`ts`、`now`、`timestamp`、`时间戳`（本轮读了 `commands.go` 的静态关键字）。新命令的关键字也不得占用这五个词。

不从一句话里摘时间戳或 UUID。`see 1700000000` 是普通搜索。

### 3.2 时间

**裸输入和剪贴板**只用非负整数，并且必须同时满足位数和区间。区间外不当作错误，退回搜索或忽略剪贴板。

| 位数 | 单位 | 区间（左闭右开） |
| --- | --- | --- |
| 10 | 秒 | `[1000000000, 4102444800)` |
| 13 | 毫秒 | `[1000000000000, 4102444800000)` |
| 16 | 微秒 | `[1000000000000000, 4102444800000000)` |
| 19 | 纳秒 | `[1000000000000000000, 4102444800000000000)` |

右端点是 `2100-01-01T00:00:00Z`。9、11、12、14、15、17、18 位都不猜。`946684800`（2000-01-01）是 9 位，裸输入不换算。

**带 `ts` 前缀**时：

- 可有一个负号。不允许正号，不允许 `1e9`。
- 无后缀：1–10 位当秒，13 / 16 / 19 位当毫秒 / 微秒 / 纳秒。11、12、14、15、17、18 位是错误 `DevtoolsUnit`，不猜。
- 后缀 `s`、`ms`、`us`、`µs`、`μs`、`ns` 优先于位数，大小写不敏感，后缀前的空格可有可无。
- 得到的瞬间，年份必须在 1–9999，否则 `DevtoolsRange`。公元 10000 年 `Format` 并不报错，所以要自己看年份。
- `ts 946684800` 覆盖裸输入够不着的 2000-01-01。`ts 946684800000` 是 12 位且没有后缀，仍然是 `DevtoolsUnit`；要写 `ts 946684800000ms`。

**日期**接受：

- RFC3339 与 RFC3339Nano。
- `2006-01-02`、`2006-01-02 15:04`、`2006-01-02 15:04:05`。
- 斜杠版 `2006/01/02`，时间部分同上。

不接受 `01/02/2006`，也不接受没有补零的月日。字符串里的偏移优先于本地。没有偏移时用 `time.Local`。

**闰秒**不处理。秒为 60 时沿用 `time.Parse` 的拒绝，界面向 `DevtoolsRange`，不把原文的 `second out of range` 给用户看。

**跳空**。`ParseInLocation` 会把不存在的钟面折进跳空之前，而且不报错（纽约 2026-03-08 02:30 折成 01:30 `-05:00`）。判定：用同一版式把结果格式化回去，钟面和输入不一致就是跳空。界面是错误行 `DevtoolsSkipped`，不给出那个被改过的时间。

**重叠**。纽约 2026-11-01 01:30，`ParseInLocation` 取第一次（`-04:00`）。对这个结果 `Add(time.Hour)` 后钟面相同、偏移不同；加上这一小时得到的瞬间就是第二次。减 1 小时在同一次实验里钟面变成 00:30，不能用来找第二次。规格只把「加 1 小时」写成检测。默认行是 Go 给出的第一次；第二行标题仍是同一个钟面，hint 写另一个偏移。重叠不是 1 小时的时区，本规格不保证认出第二次。

**结果行**，默认选中第 1 行。标题是要复制的文本，hint 是短标签。

时间戳输入：

1. 本地 `2006-01-02 15:04:05`，hint「本地」。
2. UTC，同一版式，hint「UTC」。
3. 本地 RFC3339。
4. 另一单位的整数：秒输入给毫秒，毫秒输入给秒，微秒与纳秒给秒和毫秒两行。

日期输入：

1. Unix 秒。
2. Unix 毫秒。
3. UTC 的 RFC3339。
4. 本地 `2006-01-02 15:04:05`。输入自带偏移时，这一行是那个瞬间在本地的钟面，不用本地偏移盖掉输入里的偏移。

`now`、无参数的 `ts`：

1. Unix 秒。
2. Unix 毫秒。
3. 本地 `2006-01-02 15:04:05`。
4. UTC 的 RFC3339。

默认钟面不带小数。精确的整数在后面的单位行里。Go 1.27.1 上，不带小数的版式对 500 ms 和 999 ms 没有进位；没有读 `Format` 的源码，不把「一律截断」写成库的保证。

### 3.3 UUID

**生成**

| 查询 | 行 |
| --- | --- |
| `uuid`、`uuid4`、`uuidv4` | 两行。第 1 行 v4，默认选中。第 2 行 v7 |
| `uuid7`、`uuidv7` | 只有 v7 |
| `uuid 8` | 8 个 v4 |
| `uuid7 8` | 8 个 v7 |

个数是不含正号的十进制整数。`uuid 08` 等于 8。`uuid +8`、`uuid 8x` 整段退回搜索。`uuid 0`、负数、大于 100 是错误行 `DevtoolsCountInvalid`，回车不关闭面板。

2–20 个是一行。标题是第一条，hint 是「共 N 个」。载荷是 N 行，用 `\n` 连接。回车复制全部，不复制标题。21–100 个不在面板里放半截：这一行的标题是「在窗口中打开」，回车打开窗口并带上个数，不写剪贴板。

单个 v7 再加一行：从前 48 位取出的 UTC 毫秒，版式 `2006-01-02 15:04:05.000 UTC`。批量不逐条展开。

默认文本是小写、带横线。hint 写版本和变体：版本是 `byte[6]` 的高 4 位，变体是 `byte[8]` 的高 2 位。

**解析**先看形状，再 `Parse`：

- 可有 `urn:uuid:` 前缀（大小写不敏感）和一层花括号。
- 然后是 `8-4-4-4-12` 或 32 位十六进制。
- 版本不限。v1、v5、Nil 都显示。Nil 的 hint 写版本 0、变体 `00`。
- 主行输出小写带横线。v7 同样加一行时刻；其它版本不加。

形状不符就退回搜索，不用错误行打断普通输入。

**大写和去横线**在命令面板里只改这一次的载荷，不写配置。入口是这一行的 ⌘K（§3.5）。窗口里的两个开关才写入配置。

### 3.4 剪贴板建议

`showPalette` 在模块打开、且这次是空查询时读一次剪贴板。条件全部满足才出现一组「剪贴板」，插在收藏之前：

- 去掉首尾空白后的字节数 ≤ 128。
- 整段命中 §3.2 的裸时间戳、§3.2 的日期，或 §3.3 的 UUID 字面量。带 `ts` / `uuid` 前缀的文本不当作剪贴板命中。

默认选中仍走现有的 `bestCommand`，不选这一组。方向键可以上去。用户改过查询之后，这一组消失。面板开着的时候不再读第二次，避免刚复制出去的结果立刻变成下一次按键的目标。关闭后再打开，才重新读。

读失败当空，不提示。不落盘，不写日志。模块关闭时不读，并清掉上一次留下的建议。

卡片、命令「开发工具」、CLI 不读剪贴板。打开面板时不读选中文字。

误判留在「未选中」这一层处理：10 位订单号可能落进秒的区间。它出现在独立的组里，回车的默认对象仍是原来的命令。

### 3.5 拿走结果

结果行复用 `paletteRow` 现有的默认绘制：图标、标题、右侧 hint，行高 `SizePaletteRowHeight`。不新开行高 Token。标题是给人看的，载荷另放。单个结果时二者相同；批量时标题只是第一条。

`movePaletteSelection` 现在只停在 `paletteRowCommand` 和 `paletteRowAction` 上。`runPalette` 取的是 `selectedCommand`，命令为空就返回。结果行要加进这两个函数，否则方向键选不中，回车也没有反应。

回车（以及点击这一行）：

- 错误行：留下面板，行上显示 `ErrorKey`。与非法的常亮参数一样，不关闭。
- 21–100 个 UUID：打开窗口，不写剪贴板，然后关闭面板。
- 其余：把载荷写入剪贴板，关闭面板。不调用 `recordRecent`。不弹 002 的提示。
- 写入失败：留下面板，错误行 `DevtoolsCopyFailed`。

结果行不进收藏，不进最近使用。能收藏的只有「开发工具」这条打开窗口的命令。

⌘K 不走 `command.Actions`。`palette.go` 里进入动作列表的那段在命令没有 `Actions` 时直接返回，结果行要单独分支。动作不进最近使用。

| 动作 | 时间行 | UUID 行 |
| --- | --- | --- |
| 复制 | 有，等同回车 | 有 |
| 粘贴到前台 | 第 2 步 | 第 2 步 |
| 大写 | 无 | 有，只改这次载荷 |
| 去横线 | 无 | 有，只改这次载荷 |
| 在窗口中打开 | 有，带上当前输入 | 有 |

**⌘回车粘贴**放在第 2 步，第 1 步的回车只复制。

做法：先写入剪贴板，关闭面板，再合成 ⌘V。不恢复原来的剪贴板。010 已经确认 `CGEventCreateKeyboardEvent` 与 `CGEventPost` 能解析，并且明确不模拟 ⌘C、不用 `AXIsProcessTrustedWithOptions` 弹框。本规格沿用这两条。

权限分开。Apple DTS 在 [这篇讨论](https://developer.apple.com/forums/thread/789896)（2025-10）里说 `CGEvent.post` 使用单独的 TCC `PostEvent`，系统设置里显示在「辅助功能」下，用 `CGPreflightPostEventAccess` 探测、`CGRequestPostEventAccess` 申请；它和辅助功能的 `kTCCServiceAccessibility` 不是同一个服务。`CGEventPost` 自己的文档没有写这个权限。无权限时 post 静默失败。

本轮没有做 `dlsym`，**`CGPreflightPostEventAccess` 与 `CGRequestPostEventAccess` 能否在当前 SDK 里解析，未证实**。010 也没有验证这两个符号。第 2 步实现时先探测：已有权限就粘贴；没有权限则这一次 ⌘回车只复制并关闭，不打开系统设置，不出现权限名字。若符号存在，`CGRequestPostEventAccess` 一个会话最多调一次，并且只发生在用户按了 ⌘回车的时候，不在打开面板时调。

另外三件未实测：非 ANSI 键盘上 V 的虚拟键码（ANSI 是 `0x09`，本轮没有按键实验）；安全输入框会吞掉合成按键；面板是 Panel，`Show` 拿键盘但不激活应用（003 §6.4），关掉之后前台是不是原来的应用，没有量过。初值延迟 50 ms 只是起点，**未实测**。实现时把延迟放成一个常量，方便改，不进设置。

`palette_view.go` 里输入框的 `OnSubmit` 绑定 `runPalette`，另外还有一个无修饰键的 `OverlayShortcut(0, ui.KeyEnter)`。本轮没有读 MyGo，**`OnSubmit` 会不会把 ⌘回车也算进去，未证实**。实现时先确认。若会，⌘回车要在同一处按修饰键分流，避免复制两次。

### 3.6 工具窗口

第 2 步。样式对齐 `qrWindowOptions`：`TitleBarHidden`、红绿灯在 `Space12` / `Space16`、`DisableFullScreen`、背景 `ColorCard`、创建时 `Hidden`、`DevToolsDisabled`。单实例。⌘W 与 Esc 关闭。失焦不关。按屏记几何，键 `devtools_windows`，照 `qr_placement.go` 的座位写，不动 JSON、翻译、二维码的座位。

`openDevtools` 只关浮层（`hideMenubarPanel`、`hidePalette`），不关 JSON、翻译、二维码。`showPalette` 与 `showMenubarPanel` 也不关这个窗口。关闭模块只关自己。

尺寸是新 Token：宽 480，高 440，最小高 360，最小宽与宽相同。011 给二维码也是新开的一套，不复用二维码的高。

布局：

- 时间：一个输入框。本地即时刷新，不做翻译那种 200 ms 防抖。下面是 §3.2 的结果行。点击一行即复制。⌘C 与回车复制选中行。⌘回车走 §3.5。输入为空时显示 `now` 的四行。

快捷键打开窗口时才读选中文字，顺序对齐二维码：选中文字整段命中则填入；否则剪贴板整段命中则填入；否则空。命中规则与 §3.4 相同，上限也是 128 字节。命令、卡片打开的是空窗口，不读。

快捷键默认 `Ctrl+Alt+Cmd+D`。`knownShortcutConflict` 的三组里没有这一串（本轮读了 `awake_view.go` 的表）。011 写过 Apple 系统快捷键表里的 ⌃⌥⌘ 只有 C、P、逗号和句号；本轮没有重新打开那张表。U 留给「只生成 UUID」会太窄，所以不用 U。

### 5.1 现状里不够用的地方

这些是本轮读到的行为，不是提案。

- `paletteRowKind` 有 `paletteRowHeader`、`paletteRowCommand`、`paletteRowAction`、`paletteRowActionTitle`、`paletteRowSeparator`。没有计算结果行。
- `refreshPalette` 在 `paramText` 且参数非空时进入 forced：列表里只有那一条命令。它不会显示换算结果。时间戳和 UUID 不能做成 `translate.open` 那种 `paramText` 命令。
- `splitCommandQuery` 用小写副本匹配，`RawArg` 保留原文。识别自己切分，但大小写只用于关键字，载荷保持用户输入的大小写直到格式化。
- `runPalette` 成功就 `hidePalette` 并 `recordRecent`，失败不关。面板内成功不弹 002 提示。
- `shortcutSlots` 现有 6 个：`awake`、`json`、`palette`、`panel`、`translate`、`qr`。`registerSlot` 是唯一注册路径。
- `recordShortcut` 用显式 `case` 写配置。未知 target 什么都不写，注释写明不得兜底写常亮或其它槽。
- `shortcutSlotEnabled` 对 `awake` / `json` / `translate` / `qr` 看各自的开关，其余 `return true`。漏掉 `devtools` 时，模块关掉仍会注册快捷键。
- `setSlotError`、`slotError`、`clearSlotError`、`shortcutSettingsRow` 都是按 target 分的。漏掉时，错误存不住，录制行还会显示成常亮的标签和常亮的组合键。
- `applyCLI` 对二维码先看 `QREnabled`，关闭则 `CodeDisabled`。开发工具要同样的入口判断。
- `Response.Result()` 会拷贝 `Lines`、`Translate`、`QR`。新字段若只加在 `Response` 上、不在 `Result()` 里拷贝，CLI 打印就会丢。
- `Tiles` 只有 `Awake` 和 `JSON`。翻译和二维码都没有往里加。开发工具也不加。
- `menubarPanelRows.empty` 现在是四个模块都关。

### 5.3 拟议签名

```go
// internal/devtools/devtools.go
type Kind int // KindTime / KindUUID / KindError

type Row struct {
    Title   string // 面板上的文字
    Hint    string // 右侧短标签的资源键，或已格式化的偏移
    Payload string // 复制出去的文本；批量是多行
}

type Output struct {
    Rows     []Row
    Payload  string // 默认行的载荷
    OpenN    int    // 21–100 时让窗口生成；否则 0
    ErrorKey string
}

func ConvertTime(text string, now time.Time, loc *time.Location) Output
func CurrentTime(now time.Time, loc *time.Location) Output
func GenerateUUID(version, n int, upper, plain bool) Output
func ParseUUID(text string) Output
```

`version` 只允许 4 或 7。`loc` 为 nil 时用 `time.Local`。错误都落在 `ErrorKey`，不把 `time.Parse` 的原文带出这个包。

```go
// devtools_app.go
func (a *application) openDevtools(text string, uuidN int)
func (a *application) toggleDevtools()
func (a *application) changeDevtoolsEnabled(target bool)
func (a *application) closeDevtools()
```

`changeDevtoolsEnabled` 照 `changeQREnabled` 的顺序：取消正在进行的录制；与现值相同则只刷新并返回；**先**写 `DevtoolsEnabled`；打开则 `registerSlot("devtools", …)`；关闭则 `releaseOwnedShortcut` → `clearSlotError` → `closeDevtools`；然后 `save`、刷新设置、`refreshMenubarPanel`、`invalidatePaletteAfterModuleChange`。先赋值这一步不能省，否则 `applyCLI` 仍认为模块开着。

### 5.4 第七个快捷键槽

逐处加 `devtools`，一处不漏：

- `shortcutSlots`
- `shortcutSlotEnabled`：返回 `DevtoolsEnabled`，不要掉进最后的 `return true`
- `setSlotError`、`slotError`、`clearSlotError`：各自一个字段，例如 `devtoolsShortcutError`
- `shortcutSettingsRow`：标签、录制键、模块名、`DevtoolsShortcut`
- `recordShortcut`：`case "devtools": a.config.DevtoolsShortcut = acc`，放在现有 `case` 里。不增加会写别的槽的 `default`

`restoreShortcuts` 按 `shortcutSlots` 循环，不用改。注册只走 `registerSlot("devtools", a.config.DevtoolsShortcut, a.config.DevtoolsEnabled, a.toggleDevtools)`。默认组合不加入 `knownShortcutConflict`。

关闭后：快捷键注销，重开恢复原组合；设置页留下页头开关和置灰的快捷键行，tooltip 用 `ModuleShortcutOff`；卡片不画；命令 `Available` 为 false；识别停用；CLI 回 `disabled`。

### 5.5 协议

`Protocol` 保持 1。加 action 与加 omitempty 字段都不算不兼容。

| 项 | 规定 |
| --- | --- |
| action | `ts`、`uuid` |
| `ts` 的文本 | 放在现有的 `arg`。拒绝 `bytes`、`notify`、`page`、`mode`、`follow`、`lid`、`blank`、`to` |
| `uuid` | 新字段 `count`、`uuidVersion`（0 表示默认 4）、`upper`、`plain`，均为 omitempty。不用正文帧 |
| 响应 | 不新增结果结构体。`lines` 承载全部行，`message` 承载默认行。`Result()` 已经拷贝 `Lines`；若有人把新字段只加在 `Response` 上，必须同时加进 `Result()` |
| `applyCLI` | 与二维码一样，先看 `DevtoolsEnabled` |
| `state` | 不放入生成的 UUID，避免 100 行把单行 JSON 撑过 `MaxLine` |

### 5.6 与既有规格的边界

- **001**：加一张单行卡。**002**：不弹提示。**003**：不新增 `paramText` 命令；结果行是新的行种类。**005**：窗口不用浮层规则。
- **006**：两个 action，不升协议版本。**007**：第 8 页，只用现有的页头、分组和 ③ 级快捷键行。共享下限按 §4.4 改为 456。
- **008**：新座位 `devtools_windows`。**010 / 011**：不改翻译和二维码的划词。快捷键预填若与翻译的读取冲突，打开空窗口，不读剪贴板，也不把冲突当成「没有选中」。这条与 011 §6.7 的 CAS 失败相同。

## 6. 测试

### 6.1 单元测试

不建窗口，不注册快捷键，不读系统剪贴板。剪贴板用 seam，和二维码的 `qrReadClipboard` 一样。

| 测试 | 覆盖 |
| --- | --- |
| 裸整数 | 10 / 13 / 16 / 19 位且在区间内命中；9 位 `946684800`、11 与 12 位、区间外的 10 位退回「不是时间戳」；`4102444800` 本身不在裸区间内 |
| 前缀 | `ts 946684800` 是 2000-01-01；`ts -1` 是 `1969-12-31 23:59:59` UTC；`ts 946684800000` 无后缀为 `DevtoolsUnit`；`ts 946684800000ms` 成功；后缀优先于位数 |
| 2038 与年份 | `ts 2147483648` 得到 `2038-01-19 03:14:08` UTC；年份不在 1–9999 为 `DevtoolsRange`；不依赖 `Format` 报错 |
| 闰秒 | `2016-12-31T23:59:60Z` 拒绝，文案键是 `DevtoolsRange`，不含 `second out of range` |
| 跳空 | 固定用 `America/New_York`，`2026-03-08 02:30:00` 为 `DevtoolsSkipped`，输出里没有 `01:30` |
| 重叠 | 同一时区 `2026-11-01 01:30:00` 两行，默认 `-04:00`，第二行 `-05:00` |
| 日期形状 | RFC3339 的偏移得以保留；`2006-01-02` 用传入的 loc；`01/02/2006` 与 `2026-3-8` 不命中 |
| 句子 | `see 1700000000`、一句里夹一个 UUID，都不命中 |
| UUID 生成 | v4 的版本半字节是 4，v7 是 7，变体高两位都是 `10`；默认小写带横线；`upper` 与 `plain` 只改文本 |
| UUID 解析 | 无横线、大写、花括号、`urn:uuid:` 都成主行的小写带横线；版本 0 能解析并写进 hint；Nil 变体为 `00`；形状不符则不是 UUID |
| v7 时刻 | 用已知的 16 字节构造，前 48 位与手算的毫秒一致。不把「单调」写进测试 |
| 批量 | 1 与 `uuid` 相同；2–20 一个载荷、N 行；21–100 的 `OpenN` 等于个数且载荷为空；0、101 为 `DevtoolsCountInvalid`；`uuid 8x` 不是错误 |
| 缓存 | 同一查询连续刷新，`GenerateUUID` 只被调用一次；查询改变才再调用 |
| 剪贴板 | 空查询、128 字节内、整段命中才出现组；129 字节、普通句子、模块关闭都不读；默认选中不是该组；面板保持打开时第二次刷新不读 |
| 面板执行 | 回车复制载荷而不是标题；批量复制全部行；不调用 `recordRecent`；写入失败不关闭；错误行不关闭 |
| 开关 | 关闭后命令不可用、识别停用、CLI 为 `disabled`；录制只写 `DevtoolsShortcut`；未知 target 不写任何快捷键；缺键读出默认开和 `Ctrl+Alt+Cmd+D` |
| 设置页 | 页高 144；侧栏 453；`settingsMinimumHeight` 为 456；0–6 页码不变；页序含开发工具且在二维码与快捷键之间 |
| CLI | `--notify`、超 128、`-n 0`、`-n 21`、两个版本同时给，都是用法错误；模块关闭退出 4；`Result()` 带上 `lines`；人读输出的第一行等于默认载荷 |

窗口几何、置顶、与其它工具窗口互不关闭，照二维码已有的测试补一份，使用假的窗口 seam，不创建系统窗口。

### 6.2 只能由维护者实测

1. 命令面板输入 10 位秒、13 位毫秒、一个日期、`now`、`uuid`，回车后到别的应用粘贴，确认是载荷而不是标题。
2. 空面板时剪贴板分别是时间戳、一段普通文字、超过 128 字节的文字。第一种出现建议且默认不选中；后两种没有这个组。
3. 本机时区下找一个真实的跳空和一个真实的重叠（不一定是纽约），确认跳空被拒绝、重叠有两行。
4. 第 2 步：⌘回车在有 PostEvent 权限、没有该权限、以及安全输入框三种情况下各一次。没有权限时应当只复制。
5. 快捷键在选中文字、只有剪贴板、两者都不是这三类文本时，窗口里填入的内容是否符合 §3.6。
6. 非 ANSI 键盘上合成的 ⌘V 是否仍是 V。
7. CLI：应用没运行时能否拉起；`--json` 在状态快照较大时是否因 `MaxLine` 失败而不是截断。
