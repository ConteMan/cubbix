# R01 · 设计系统第一版

目标：为 Cubbix 建立 Token、可复用组件，以及「通用／关于」× 中文／英文 × 浅色／深色的 8 张设置样张。评审状态：待维护者评审；本轮没有维护者已批准的新增意见。

## 本轮规则与取舍

沿用仓库已定规则：无系统标题栏，背景空白处可拖动；窗口／卡片与条目／控件使用 12／8／6 三档圆角；统一使用固定版本 Lucide。为保持低信息密度，普通设置行省略显而易见的说明与正常状态标签，组件仍提供可选辅助行。

本轮提案：窗口 840 × 580、侧栏宽 168，右侧内容最大宽 528 并居中；分组标题在卡片外，行高 48，卡片内用细分隔线。「通用」把语言与开机启动放入同一组；「关于」把版本检查、更新内容、自动更新放入同一组。

「关于」样张演示下载已完成后的提示，提示仅在该状态出现；版本号 0.1.0、开关开启均为示例，不代表已发布版本或产品默认值。检查更新使用纯图标按钮并配 tooltip，下载完成后只保留「重新打开」这一项操作。

## Token、组件与写死统计

65 个样式 Token：18 个主题颜色、42 个数值、5 个字符串；名称与未来 Go 导出字段一一对应，详见 [映射表](../../token-index.md)。另有 35 个中英文文案键及对应 `Copy…` 变量。

29 个 reusable：14 个 Lucide 图标，及设置行、开关、分段选择、图标按钮、tooltip、文字按钮、分隔线、分组卡片、导航项、状态图标、菜单项、菜单栏下拉菜单、下载完成提示、版本检查控件、设置窗口。详见 [组件索引](../../component-index.md)。源文件中有 70 个 ref，统计包含嵌套 `descendants`。

| 画布属性 | 写死次数 | 不同写死值 |
| --- | ---: | ---: |
| 颜色 | 0 | 0 |
| 圆角 | 0 | 0 |
| 字号 | 0 | 0 |
| 间距（padding / gap / letterSpacing） | 0 | 0 |

统计递归覆盖 `children`、`descendants` 及覆盖属性，不含变量定义。x/y 与 width/height 是画布位置和几何尺寸，不计入间距。CLI 当前不保留尺寸变量绑定；尺寸值与文案兼容处理见 [交接说明](../../README.md)。脚本与明细见 [audit.json](audit.json)。

## 验证

原生布局检查遍历 8 张样张的 464 个展开节点，0 处裁切；人工核对中文、英文、浅色、深色及组件状态导出。数值审计通过，无缺失变量、悬空 ref、未完成占位符或样式 Token 漂移。证据与图片哈希见 [render-validation.json](render-validation.json)。

仓库骨架尚未提供 `scripts/selftest.sh`，本轮无法运行该合并检查；未以设计检查替代应用自测。应用菜单栏、快捷键、焦点和输入法行为仍需在实现阶段实测。
