# R05 · 常亮格子

目标是打开菜单即看出是否保持唤醒、保持屏幕还是任务以及剩余条件；常用操作是开启、更换时长和停止。本轮为普通常亮设计，合盖不休眠延后至 #4。

## 样张

[中文浅色](zh-CN-light.png) · [中文深色](zh-CN-dark.png) · [英文浅色](en-light.png) · [英文深色](en-dark.png)。画布保留可编辑的可复用组件和四种语言／主题样张；示例时间和进程为演示数据。

## 取舍

- 菜单使用原生菜单能力：状态行、勾选、子菜单、分隔线和快捷键；开启后状态展示模式及倒计时，其他示例展示截止时刻、跟随进程和不限时。仅保持任务允许屏幕熄灭。选择时长或进程作为结束条件；停止立即解除。
- 自定义时长、截止时刻和进程选择使用无标题栏小窗口，Esc 关闭、回车确认；进程列表可搜索，Agent 类进程优先。进程图标是示意，实际应使用进程关联应用图标，缺失时使用统一的回退图标。
- 格子页提供常亮开关；JSON 为禁用占位。快捷键默认 ⌃⌥⌘K，录制状态与冲突示例均展示；冲突 alert 的原因以悬停或键盘聚焦 tooltip 呈现，不弹窗，提交前应阻止使用已知冲突组合。
- 电池切换采用系统通知：中文标题「已切换到电池供电」、正文「常亮仍在运行。」；英文标题 “Switched to battery power”、正文 “Keep awake is still active.”
- 猫标展示未开启闭眼、开启睁眼的初步提案，沿用现有菜单栏模板的猫与盒子轮廓。只供评审，微小尺寸下的眼部线条由维护者在品牌 pen 中定稿；品牌母版与输出均未修改。
- 界面沿用 R04 黑白灰，图示无自定义菜单控件；颜色、圆角、字号和间距均使用变量。语言资源同步保存在 `design/locales/`；样张文字实例按语言覆盖，以适配 headless CLI 的文本内容限制。

## 待决定

- 开启时沿用上次模式和时长，还是每次使用固定默认值；截止时刻早于当前时是否指次日。
- 跟随进程的同名实例、退出重启及无法读取进程列表时的行为；Agent 排序规则和图标回退细节。
- 系统快捷键冲突可检测范围与冲突时保留原快捷键的具体交互；tooltip 触发和焦点行为。
- 电池通知是否提供关闭常亮的系统通知操作，以及通知权限关闭时的降级行为。
- 猫标闭眼提案的可辨识性、最终轮廓及是否保留菜单栏剩余时间文字。

## 尚需完善

- 进程列表目前使用示意符号，尚未绘制真实应用图标及统一的图标回退。
- 冲突原因目前以普通文字示意，尚未画成 tooltip 视觉；录制状态单独示意，尚未置于快捷键控件中。
- 猫标提案使用现有 Logo/Mark 矢量组件，尚未基于菜单栏模板 PNG 对照制作，因此不能视为模板尺寸下的定稿提案。

## 验证

headless CLI 复开导出四张 1× PNG，展开布局检查无裁切；[审计](audit.json)中颜色、圆角、字号及间距的写死次数均为 0，无缺失变量或悬空引用。没有浏览器检查，也没有上传截图附件。本轮为静态设计，未验证原生菜单、快捷键注册或系统通知的运行时行为。
