## 目标

1. 「格子」改称「模块」。
2. 设置按模块分组：低电量下限回到常亮模块里，模块与它的快捷键在同一页。
3. 快捷键与模块联动：模块关掉后快捷键注销、同一页上置灰并给一句原因。
4. 统一「设置行说明」的三级写法，并把这套语言写进设计规范。
5. 通用页的「命令行工具」从 ✓ / ✕ 两个图标改成开关，六种链接状态各有明确落点。

## 借鉴的参考

维护者提供了一份深色 macOS 设置页作为设计参考。本轮借鉴的是**结构**，不是配色：

| 参考做法 | R16 的落点 |
| --- | --- |
| 侧栏每项「圆角方块图标 + 名称」，每个模块单独一项，选中底色高亮 | 侧栏 5 项：通用 / 常亮 / JSON / 快捷键 / 关于；图标方块 28、`ColorControl` 底、单色图标；选中 `ColorAccentSoft` |
| 每页顶部「头部卡片」：图标 + 名称 + 一行灰字说明 | 常亮、JSON、快捷键、通用、关于五页都画；说明文字见 007 §8 |
| 分组上方的小号灰色分组标题 | 24 高、12/500 `ColorTextSecondary`；模块页是「设置」「快捷键」，快捷键页是「Cubbix」「反馈」 |
| 行 = 图标 + 标题 + 第二行灰字，右侧状态点 + 文字或 `›` | 有意义的行才加前置图标；状态点中性（`ColorText` / `ColorTextDisabled`）；只有「更新内容」用 `›` |
| 页面级操作放窗口右上角 | 放头部卡片右侧：模块页是总开关，关于页是「检查更新」 |

**配色不参考**：Cubbix 继续用黑白灰。状态点不用绿色——已启用 / 已是最新用实心中性深灰（`ColorText`），关闭 / 未安装用 `ColorTextDisabled`；只有错误与异常用现有 `ColorDanger` + `triangle-alert`。没有新增彩色 Token。

## 信息架构

比较过两种（详见 007 §2.6）：

- A：单一「模块」页 + 分组卡片（侧栏 4 项）。
- **B（本轮采用）**：每个模块一个侧栏项（侧栏 5 项）。

采用 B 的理由：模块与快捷键同页，「关掉常亮 → 常亮页里的快捷键立刻置灰」是当场可见的事实，不需要再切一页确认；参考稿也把每个功能作为一级导航；每页都有头部卡片，说明这页做什么。

## 每张板的六组内容

1. **模块页（4 张窗口）**
   - 常亮开启：头部卡片（sun + 常亮 + 说明 + 总开关）、分组「设置」里的低电量下限（② 级说明，占满整行）、分组「快捷键」里的开关常亮。
   - 常亮关闭：设置组连同标题一起收起；快捷键行保留、置灰并带 `info`（tooltip：常亮已关闭，快捷键已注销）。
   - JSON 开启 / 关闭：只有「快捷键」一组；关闭时新建 JSON 窗口行置灰。
2. **快捷键页**：Cubbix（命令面板、卡片面板）+ 反馈（反馈方式带 ③ `info`，提示位置用 5 段定位图形）。
3. **关于页**：头部卡片右侧「检查更新」；版本行「0.5.7 + 状态点 + 已是最新版本」；更新内容行 `›`；自动更新 ② 级说明「启动时和每 24 小时检查一次 · 上次检查 13:20」（该时间戳现在不存在，需要实现时补 `updateState.CheckedAt`）。
4. **通用页（3 张）**：命令行工具关闭 / 开启 / 链接冲突。开关代替 ✓ / ✕；异常状态在开关左边加 `triangle-alert`，原因放 tooltip。
5. **命令行工具异常（2 张）**：链接失效、应用不在「应用程序」。
6. **品牌区两方案**：A（推荐）猫标落在导航图标列、名称与导航文字左对齐、品牌与导航之间一条分隔线；B 贴左边、只靠间距。其余窗口都用 A。
7. **设置行说明三级**：① 行内小字（开机启动，说明比标题小一号并底部对齐）、② 第二行（自动更新，含「上次检查 13:20」）、③ `info` + tooltip（反馈方式），tooltip 以独立气泡画出。

关于页的「上次检查」在从未检查时整段省略；检查失败时时间照常前进，失败只由版本行的红色 `triangle-alert` 表示（不把错误句子写进第二行）。命令行工具三种异常态的警示图标都是红色线条图标，没有红色底块。

## 设置行说明三级（本轮定下的规则）

| 级别 | 形态 | Token | 行高 |
| --- | --- | --- | --- |
| ① | 标题右侧一行灰色小字 | `FontSizeSmall` 12、`ColorTextSecondary`、间距 `Space8` | 48 |
| ② | 标题下方第二行，占满整行宽度、单行省略 | 同上，标题与第二行 `Space2`；有前置图标时缩进 `SizeIcon` + `Space8` | 64 |
| ③ | 标题右侧 `info` 图标 16，详情放 tooltip | `SizeIcon`、tooltip 12 / `ColorTooltipText`、最大宽 320 | 48 |

判断顺序：不写会不会做错 → 不会就不写；一句话、控件窄 → ①；太长或控件宽 → ②；两句以上或随状态变化 → ③。逐行对照与全部文案见 007 §3.4 与 §8。

## 尺寸与 Token

- 侧栏宽 `SizeSidebarWidth` 144；内容宽 `SizeContentMaxWidth` 528；窗口 720 宽。
- 头部卡片 56、分组标题 24、导航项 40、普通行 48、② 级行 64、图标方块 28、状态点 6。
- 所有颜色、字号、圆角、间距引用既有变量；**不需要新颜色 Token**；警示图标用 `ColorDanger` 描边，不是色块。
- 建议新增三条 Size Token：`SizeNavItem` 40、`SizeGroupHeader` 24、`SizePageHeader` 56；不新增时按 `SizeNavHeight`、`Space8`、`Space16` 组合得到（007 §7.1）。
- 最小窗口提案 720 × 380（快捷键页自然高 378）；所有页面都不需要滚动。
