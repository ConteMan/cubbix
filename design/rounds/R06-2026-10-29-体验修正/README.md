# R06 · 设置窗口体验修正

本轮按维护者 0.0.3 工作单完成：先在 `design/cubbix.pen` 补充设置内更新子页及放大布局，再实现原生界面；沿用 R04 黑白灰、猫标与 Lucide 0.468.0 图标。R01–R05 历史画板和预览保持原样。

## 确定的行为

- 「关于 → 更新内容」只切换右侧内容；顶部左侧返回图标的 tooltip 为「返回 (Esc)」／「Back (Esc)」，按一次 Esc 返回关于页，包括 tooltip 已展开时。⌘W 隐藏整个设置窗口。
- 历史记录按版本倒序，版本号和发布日期同行，下方列用户可感知的变化；只给运行中的版本一处弱化的「当前」／「Current」标记。中文与英文分别来自根目录两个 CHANGELOG，做法记入 ADR 005；远程请求失败仍可阅读内置记录。
- 最小窗口为 720 × 340：关于页带错误提示 244，再加就绪卡片及留白 96。更新内容滚动，不用整个历史的自然高度决定最小窗口。窗口可拖动放大，尺寸写入原有配置；切换页面不改尺寸。
- 侧栏宽 144 并延伸至窗口底部；右侧内容最大宽 528，水平居中，四周留白 24。为系统红绿灯预留左上空间，空白区域仍可拖动窗口。
- 窗口显示时使用 Regular，隐藏或关闭时使用 Accessory；原生应用菜单包含关于、设置和退出，编辑菜单提供系统标准的撤销／重做／剪切／复制／粘贴／全选，应用文案随语言切换。

## 运行验证

`ui.Tester` 覆盖双语子页切换、返回按钮、tooltip 展开后的 Esc、侧栏导航、当前标记、最小尺寸与放大居中；配置测试覆盖旧文件兼容与尺寸保存。独立的 AppKit 测试进程始终隐藏窗口，只读取 NSApplication 的 activationPolicy，验证隐藏状态下 1→0→1 的策略值、编辑菜单原生 action、可调整大小的 styleMask、minSize=720×340、系统关闭按钮及 1000×600 尺寸落盘；同时断言窗口不可见、未聚焦且应用未激活。

[界面截图与检查记录](runtime/) 使用 `ui.Tester` 对真实视图做内存渲染，覆盖更新子页的中英文／浅深主题和 1000×600 设置窗口（2× PNG）。为避免干扰全屏应用，本轮最终交付跳过原生窗口截图；这些图片不作为原生窗口焦点或系统菜单栏截图。原生检查进程直接在后台运行，窗口全程隐藏，不经过应用的显示／Focus／激活入口，不发送真实鼠标事件，不使用 Computer Use，不切换 Space，不注册开机启动，不下载或安装更新。

本轮以 `./scripts/selftest.sh` 全部通过为交付条件，PR 仅供评审；不合并、不发布 0.0.3，不修改 v0.0.1／v0.0.2 的公开 Release 正文。
