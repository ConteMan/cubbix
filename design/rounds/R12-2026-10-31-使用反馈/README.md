## 目标

把维护者已定的使用反馈画成可评审的一版：主窗口红绿灯恢复标准符号、侧栏品牌横排、菜单栏 JSON 卡片去掉整条新建按钮、JSON 窗口标题单名前可改、预览只在有结果后出现、行号与折叠箭头对齐，并在同一版里补回缩进对齐线与 JSON 窗口底栏边界。不再出备选。

## 决定

1. **主窗口红绿灯**：关闭、最小化、缩放三个都带标准符号——×、−、两个对角三角。缩放即绿色按钮的还原行为，全屏仍然关闭（运行时 `DisableFullScreen` 不变），因此 `DisableMinimize` 与 `DisableMaximize` 需要放开。设计稿只画原生控件的样子，颜色仍由 macOS 提供，不用自绘按钮盖住系统按钮；画板沿用既有约定，圆点为 `ColorTextDisabled`，符号用 `ColorWindow` 反白。
2. **侧栏品牌**：侧栏宽度仍是 144，内容宽 120。猫标在左（`SizeBrandMark` 20，直接用既有 `Logo/Mark`），名称 Cubbix 在右，字号 `FontSizeTitle`、字重 600、行距 `LineHeightTitle`，名称行盒高也是 20，与猫标垂直居中，间距 `Space8`。整组 120 × 20，左对齐侧栏内容，仍在红绿灯下方：红绿灯 12 高、距顶 12，间隙 `Space16` 后品牌从 y=40 开始。不再用「猫标在上、名称在下、整组高 54」的排法，中英都一样。
3. **菜单栏 JSON 卡片**：删掉卡片底部整条「新建 JSON 窗口」按钮，只保留标题行右侧的加号图标按钮（28 × 28，`RadiusControl`，`focus-visible`），tooltip 仍为「新建 JSON 窗口 (⌃⌥⌘J)」。窗口列表、六个以上窗口的折叠计数行、常亮卡片都不动；画板同时给出列表态与折叠态。
4. **JSON 窗口标题栏**：标题与三个红绿灯同一条垂直中心线——红绿灯距顶 16、高 12，中心 22；标题在 44 高的栏内居中，中心也是 22。标题左侧空隙改为 `Space16`，即距窗口左边 12 + 52 + 16 = 80。未打开文件的窗口一律显示固定名 JSON，不再出现 JSON 2、JSON 3（`JSONWindowNameNumbered` 因此空置）。标题可单击就地编辑：编辑态显示 24 高输入框、焦点描边与光标，Enter 确认、Esc 取消、清空恢复默认；打开文件显示文件名，用户改名后用自定义名，换文件回到新文件名。窗口标题、系统标题、窗口菜单与卡片列表是同一个名字，画板用四种状态加同一份卡片列表佐证。
5. **预览与底栏**：还没有 `this` 结果时不画右侧预览、不画分隔条，编辑区占满宽度；出现结果或错误后才加分隔条与预览，分隔条在底栏上沿停下，不穿过底栏。底栏始终是窗口最底部的一整行，横跨编辑区与预览区，不随左侧容器变窄；从左到右是 `this`、占满剩余宽度的输入框（背景 `ColorControl`、圆角 `RadiusControl`、高 `SizeNavHeight`）和靠窗口右缘的工具按钮。底栏上沿用 `StrokeHairline` 与 `ColorSeparator` 画一条通栏边界线，编辑区、分隔条、预览区都停在这条线上。无结果、有结果、出错三种状态的底栏完全相同。错误只在预览区放一个 `triangle-alert` 图标（`ColorDanger`、`SizeIconLarge`），不写说明文字，原因仍在 tooltip。
6. **折叠箭头与行号**：同一行共用一个 24 高的行（`SizeJSONLineHeight`）。行号单元 44 宽（`Space12` 内缩），折叠单元 24 宽（`Space4` 内缩），两者都按行居中；行号 13/1.5、箭头 16，垂直中心都在 y=12。局部放大板按 4 倍画出这一行，并用同一条中心线标出对齐关系。
7. **缩进对齐线**：所有有嵌套 JSON 的编辑区都画同层级竖线：每一级缩进一条，颜色 `ColorSyntaxIndent`，宽 `StrokeHairline`，从该行的缩进起点贯通整行高。缩进步长按代码字体 0.6em 计算（13px 每级 15.6），线落在该级缩进结束、正文开始处；局部放大那一行也有缩进，同样按 4 倍画出这条线。

## 校验

- `python3 design/scripts/layout.py`：148 个顶层节点，最小间距 80，`errors` 为空，`passed: true`。
- 复开导出：6 张 2× PNG，展开节点 1833，布局问题 0，历史根节点完全不变（`render-validation.json`）。
- 底栏与边界：7 个 JSON 窗口（四张主题板各 1、预览板 3）底栏都是 840 × 44，边界线 840 × 1；三种预览状态的底栏一致。
- 缩进线：7 个编辑区共 63 条层级竖线，一级 x=94.6、二级 x=110.2，宽 1、高 24；局部放大板另有一条 4 倍竖线。
- Token：颜色、圆角、间距写死 0，`tokenDrift`、缺失变量、悬空引用与未完成 placeholder 各 0。审计范围内（颜色、圆角、字号、间距）唯一的非 Token 值是局部放大板的两处字号 52（`FontSizeBody` × 4）。
