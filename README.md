# Cubbix

> cubby + x：一格一个小工具。

Cubbix 是维护者自用的 macOS 菜单栏工具箱，基于 [MyGo](https://github.com/egoist/mygo) 构建。它把平时只在别的软件里用到一两个功能的场景，集中到一个常驻、轻量、贴合个人习惯的应用里。每个功能是一个独立「格子」，逐个加入，不做插件市场。

## 格子

| 格子 | 用途 |
| --- | --- |
| 常亮 | 防止休眠：区分「保持屏幕」与「只保持任务」，可设时长、到某时刻或跟随进程结束，快捷键切换 |
| JSON | 多窗口、可置顶的 JSON 查看与编辑，底部 `this` 表达式用 JS 处理数据 |

进度和任务以 GitHub Issues 为准。

## 开发

要求 Go 1.27.1（MyGo 会自动下载工具链）、Node.js 22 或更新版本与 npm，不使用 CGO。

```sh
./scripts/selftest.sh   # vet、测试、设计检查及 ad-hoc 打包；不公证
```

## 发布构建

先提交全部改动，使工作区保持干净。`./scripts/release.sh` 校验 `mygo.json`、应用版本和 `CHANGELOG.md` 的首个 `## x.y.z` 章节一致，运行自测，再由固定版本的 MyGo 生成 Developer ID 签名、公证的应用、DMG、签名更新归档及清单。构建结果位于 `build/`，默认不上传。

发布环境需提前准备 Developer ID 证书、公证钥匙串 profile 及仓库外的更新私钥。私钥文件权限为 0600，可用 `CUBBIX_UPDATE_KEY_PATH` 覆盖脚本的默认路径；脚本只在构建进程中注入 `MYGO_UPDATER_PRIVATE_KEY`，不要开启命令追踪或将密钥写入日志。显式运行 `./scripts/release.sh --upload` 才会上传到草稿 Release，发布由维护者复核后进行。

自动更新在启动时和每 24 小时检查；关闭后取消自动请求，手动检查仍可下载和验签。安装成功只替换磁盘应用，当前进程继续运行，用户通过关于页或菜单栏的重启入口切换版本。菜单栏先采用新增菜单项提示，沿用现有模板图标，尚无持续可见的角标。常亮会话会在「重启更新」前写入配置，并按原截止时间恢复；跟随会话会核对原进程的 PID 和启动时间。JSON 是工具而非文档，重启更新不检查未保存内容。

## 常亮

菜单提供「保持屏幕常亮」和「仅保持任务」；首次快速开启为屏幕常亮 1 小时，之后记住上次模式与时间选择。可选 30 分钟、1／2／4 小时、自定义小时和分钟、24 小时制截止时刻、不限时，或跟随某个进程。选择时长会立即开启；已开启时切换模式保留当前截止时间或跟随目标。早于或等于当前时间的截止时刻解释为次日。

常亮使用系统 `caffeinate -d -i` 或 `-i`，有限会话附带 `-t`，所有会话始终附带 `-w <Cubbix PID>`。应用退出、崩溃或被强制终止后，断言由系统释放。跟随绑定具体 PID 和启动时间，进程结束或 PID 被复用即停止，不接续同名进程。跟随列表只列普通图形应用与当前用户挂在终端上的进程，可搜索名称／PID。shell 默认隐藏，输入完整名称（如 `zsh`）才显示；Agent 优先，其余按名称排序。配置项 `awake_agents` 是逗号分隔的优先名称列表，默认 `codex,claude,gemini,aider`。方向键上下选择、回车确认、Esc 取消。搜索防抖 100ms，列表只渲染可见行；命令行进程显示 Lucide terminal，图形应用图标按可见行后台加载并按 bundle 路径缓存。列表读取失败或目标已结束时不确认。合盖不休眠不包含在此功能中。

「格子」可停用常亮并结束正在运行的会话；JSON 同样可以单独停用，停用即关闭它的窗口与快捷键。「快捷键」默认 ⌃⌥⌘K，点击后按组合键录制，Esc 保留原值。录制时临时暂停本应用菜单快捷键和两个格子的全局快捷键，结束录制后恢复；已知的系统组合、本应用菜单组合及系统拒绝注册的组合只显示 alert 与 tooltip，不替换原值。系统冲突检查包含常见的 Spotlight、输入源、截图、任务控制、切换应用和锁屏组合，以及原生注册失败；无法穷举用户自定义或其他软件的所有快捷键。

会话持续写入配置。只有用户主动「重启更新」会写入一次性的恢复标记，下次启动按剩余时间恢复；已过期、目标已结束或格子已停用则丢弃。普通启动（包括崩溃后重开）默认关闭，避免意外长期开启；仍保留上次模式和时间选择。恢复标记启动时即消耗，保存失败会阻止发起更新重启。

从电源切到电池、且常亮正在运行时，提交一条当前语言的系统通知，会话继续。生产路径使用 MyGo 的通知接口，首次需要提醒时系统会询问一次通知权限；被拒绝时只静默记录，本次运行不再发送或重试，不弹应用自定义提示。测试使用替换发送器打桩，绝不调用真实 Show 或通知授权接口。

界面和验证记录见 [R05 运行截图](design/rounds/R05-2026-10-29-常亮/runtime/README.md)。截图通过 `ui.Tester` 内存渲染，无原生窗口截图、真实键盘事件或前台激活。菜单图为真实原生菜单模型的测试渲染；原生模板图切换、菜单安装、全局快捷键注册／释放和三个无标题栏窗口通过隐藏 AppKit 进程验证。

## JSON

从菜单或全局 ⌃⌥⌘J 新建窗口；仅创建时读取剪贴板中可解析的 JSON，已有窗口获得焦点不会覆盖内容。「快捷键」页可录制新组合，检查本应用、系统及另一格子的冲突。每个窗口独立编辑、求值和置顶（窗口内 ⌥⌘P）。窗口名称显示在红绿灯右侧并同步到系统窗口标题与菜单列表：新建窗口依次为 JSON、JSON 2、JSON 3，打开的文件显示文件名。菜单直接列出窗口，达到 6 个时收进子菜单，选择即切到对应窗口。

⌘O 或拖入一个文件会直接替换当前内容，不提示保存；多文件拖入取第一个。⌘S 保存，⌘⇧S 另存为，路径仅由原生选择器或文件拖入确定。原文可复制（⌘⇧C），⌘C 保留为复制选区。首版底部工具只有重新格式化、折叠全部、展开全部、压缩并复制；格式化可撤销，压缩复制不会改写文档。支持标准 JSON，不提供 JSONC／去注释和其他转换。

窗口左右分栏：左侧编辑区、右侧结果区，中间的分隔条可拖动，也可用方向键调整，宽度比例写入配置（默认 60／40）。底部一行左侧是固定 `this` 输入框，宽度与编辑区对齐，右侧是 4 个工具按钮；输入 `.data.items.length` 或 `.data.items.map(x => x.val)` 等后缀。JSON 和表达式改变后等待 120ms，每个任务创建独立 Worker，包含解析、求值和序列化的任务预算为 200ms；完成、过期、关闭或超时都会终止 Worker，下一次修改可重新求值。数字（含 NaN／Infinity）、字符串、布尔值、null、数组、对象和 undefined 显示在右侧结果区；没有表达式时结果区保持空白，结构结果可折叠和滚动。无效 JSON、异常或超时立即清空旧结果，仅在输入框右侧用 alert 与双语 tooltip 提示。编辑区按类型着色（键名、字符串、数字、布尔值与 null 各一色，浅深主题各一套 Token，达到 WCAG AA），并为每一级缩进画一条弱化的竖向参考线；界面元素仍只用黑白灰。

超长单行保持原文，暂停语法高亮与折叠，用一个 gauge 图标提示；复制、滚动、编辑和显式格式化仍可用。实测后采用 **单行超过 100,000 个 UTF-16 单元，或全文超过 32 Mi 个 UTF-16 单元** 的阈值；普通多行 10 MiB 文档保持高亮。单次打开限制为 64 MiB，结果序列化后最多 1 MiB（UTF-8）；超出上限时给出图标提示。窗口只在按 ⌘W、点红绿灯关闭或退出应用时关闭，失去焦点不关闭也不隐藏；关闭、退出和更新重启都不提示保存。⌘S／⌘⇧S 仍是显式保存，保存失败只显示 alert。

编辑器使用固定的 CodeMirror view 6.43.15、state 6.7.6、language 6.13.1、lang-json 6.0.2；esbuild 0.28.2 构建。源码、精确依赖锁与产物都在 `frontend/`；`./scripts/build-frontend.sh` 在仓库外的临时目录安装依赖并重新构建，`--check` 比较全部产物并运行真实 Worker 单测，已接入 selftest。Go 嵌入并通过 MyGo 本地协议提供页面，运行时完全离线，CSP 为 `connect-src 'none'`，禁止外部导航与新页面。`unsafe-eval` 用于 blob Worker 的表达式编译；Worker 不包含 Go 桥接或 DOM，这不构成任意代码的完整安全沙箱。文案来自语言资源，浅深灰阶样式由 `tokens.go` 注入；等宽字体优先 JetBrains Mono，未安装时使用系统 monospace。

2026-10-30 的隐藏 WebKit 实测见 [性能数据与运行截图](design/rounds/R07-2026-10-30-JSON/runtime/README.md)：10,494,008 字节／99,003 行的同步编辑器载入 25ms，20 次插入中位数 14ms、P95 17ms；10,491,391 字节的所选文件经过 Go 读取、桥接、自动格式化和防抖验证后约 196ms 可用。64,014 字符单行保持高亮、载入 3ms；100,014／120,014／1,000,014 字符单行进入大文件模式，载入及单次编辑为 0–1ms（计时精度为毫秒）。这些是隐藏页面的测量，不等同于前台逐帧动画或系统文件选择器的交互延迟。
